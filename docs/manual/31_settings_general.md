# 設定 — 「一般」タブ

この文書は、ユーザー設定ウィンドウの「一般」タブにある項目の説明です。
画面の配色、表示言語、応答完了のデスクトップ通知を切り替えます。

## どこにあるか

サイドバーの「設定」(または `Ctrl` + `.`) でウィンドウを開き、左側のタブから「一般」を選びます。
既定で最初に開くタブです。

## 誰が使えるか

ログインしている全員。変更は自分の画面にだけ効きます。

## 項目

| 項目                 | 意味                                                                            | 既定                                   |
| -------------------- | ------------------------------------------------------------------------------- | -------------------------------------- |
| 「テーマ」           | 画面の配色。「⚙️ システム」「🌑 ダーク」「☀️ ライト」から選びます。             | ⚙️ システム                            |
| 「言語」             | 画面表示の言語。                                                                | ブラウザの設定などから自動で決まります |
| 「デスクトップ通知」 | いま画面に出していないチャットで応答が終わったときに、OS の通知を出すかどうか。 | オフ                                   |

いずれも、選んだ・切り替えた時点ですぐ反映されます。「保存」ボタンはありません。

## 操作手順

### 配色を変える

1. 「テーマ」の選択欄を押します。
2. 「⚙️ システム」「🌑 ダーク」「☀️ ライト」から選びます。

「⚙️ システム」を選ぶと、OS やブラウザの設定 (ダークモードかどうか) に合わせて自動で切り替わります。

チャット画面右上の太陽 / 月のアイコンでも、ライトとダークをその場で切り替えられます。

### 表示言語を変える

1. 「言語」の選択欄を押します。
2. 一覧から言語を選びます。選んだ時点で画面の表記が切り替わります。

### 応答完了の通知を受け取る

別のチャットを開いていたり、他のアプリを見ていたりする間に応答が終わったことを知らせます。

1. 「デスクトップ通知」をオンにします。
2. ブラウザが通知の許可を尋ねてきたら、許可します。

許可しなかった場合、スイッチは自動でオフに戻り、
「サイトの通知許可が拒否されているため、応答通知を有効にできません。ブラウザ設定から許可してください。」
と表示されます。ブラウザの設定で通知を許可してから、もう一度お試しください。

通知の音を鳴らすかどうかは「インターフェース」タブの「通知音」で切り替えます。

## 注意点

- 「テーマ」と「言語」は、使っているブラウザに保存されます。別の端末や別のブラウザでは
  改めて設定してください。
- 「デスクトップ通知」は、ブラウザ側で通知がブロックされていると働きません。
