# ワークスペース > 設定: 一般

この文書は、サーバー全体の基本設定 (バージョン確認、認証、通知、外部ツールサーバー接続) を行う画面の説明です。

## どこにあるか

左サイドバー > ワークスペース > 「設定」 > 「一般」

「設定」タブを開くと最初に表示されるのがこの画面です。

## 誰が使えるか

**管理者のみ**です。管理者以外には「設定」タブ自体が表示されません。

## 保存の仕方

この画面の設定はすべて、**画面右下の「保存」を押した時点でまとめて反映されます**。ただし「LDAP」の有効・無効スイッチだけは、切り替えた時点で即座に反映されます。

## 「一般」の節

| 項目           | 意味                                                   |
| -------------- | ------------------------------------------------------ |
| 「バージョン」 | 動作しているアプリケーションのバージョン。表示のみです |

## 「認証」の節

| 項目                             | 意味                                                                                                    | 備考                                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 「デフォルトのユーザー役割」     | 新規登録されたアカウントに与える役割                                                                    | 「保留中」「ユーザー」「管理者」から選びます。「保留中」にすると管理者が承認するまで使えません |
| 「新規登録を有効にする」         | 利用者が自分でアカウントを作れるようにします                                                            |                                                                                                |
| 「API キーを有効化」             | 利用者が API キーを発行できるようにします                                                               |                                                                                                |
| 「API キーのエンドポイント制限」 | API キーで叩ける API を限定します                                                                       | 「API キーを有効化」がオンのときだけ表示されます                                               |
| 「許可するエンドポイント」       | 制限を有効にしたとき、許可する API のパスをカンマ区切りで入れます (例: `/api/v1/chats, /api/v1/models`) | 制限がオンのときだけ表示されます                                                               |
| 「JWT 有効期限」                 | 無操作が続いたときにログインが切れるまでの時間 (操作するたびに数え直します)                             | 例: `30m`、`1h`、`10d`。使える単位は `s`, `m`, `h`, `d`, `w`。`-1` で無期限                    |
| 「LDAP」                         | LDAP サーバーによる認証を有効にします                                                                   | オンにすると設定欄が開きます                                                                   |

### LDAP の設定欄

「LDAP」をオンにすると、次の欄が現れます。

| 項目                               | 意味                                                                                              |
| ---------------------------------- | ------------------------------------------------------------------------------------------------- |
| 「ラベル」                         | ログイン画面に出す表示名                                                                          |
| 「ホスト」                         | LDAP サーバーのホスト名                                                                           |
| 「ポート」                         | ポート番号。既定は 389 (TLS 有効時は 636)                                                         |
| 「アプリケーション DN」            | 検索時に bind するアプリケーションアカウントの DN                                                 |
| 「アプリケーション DN パスワード」 | 上記アカウントのパスワード                                                                        |
| 「メールの属性」                   | サインインに使うメールアドレスに対応する LDAP 属性 (例: `mail`)                                   |
| 「ユーザー名の属性」               | サインインに使うユーザー名に対応する LDAP 属性 (例: `sAMAccountName`、`uid`、`userPrincipalName`) |
| 「検索ベース」                     | ユーザー検索のベース (例: `ou=users,dc=foo,dc=example`)                                           |
| 「検索フィルター」                 | 検索条件 (例: `(&(objectClass=inetOrgPerson)(uid=%s))`)                                           |
| 「TLS」                            | TLS を使うかどうか                                                                                |
| 「証明書パス」                     | TLS を使うときの証明書のパス                                                                      |
| 「暗号スイート」                   | TLS を使うときの暗号スイート。既定は `ALL`                                                        |

## 「機能」の節

| 項目                 | 意味                                                         |
| -------------------- | ------------------------------------------------------------ |
| 「ユーザー Webhook」 | 利用者ごとの Webhook 通知を有効にします                      |
| 「WebUI URL」        | この画面の公開 URL。通知内のリンクを組み立てるのに使われます |
| 「Webhook URL」      | 通知の送信先 URL                                             |

## 「ツール」の節 — 外部ツールサーバーの接続

**「ツールサーバーを管理」** では、OpenAPI 互換の外部ツールサーバーへの接続を登録します。ワークスペースの「ツール」タブで作る Python のツールとは別の仕組みで、外部で動いているサービスをツールとして繋ぎ込むためのものです。

- 右の「+」(「接続を追加」) で新しい接続を追加します。
- 追加済みの接続は行として並び、URL と API キーをその場で編集できます。歯車のアイコン (「設定」) から詳細ダイアログが開きます。
- 詳細ダイアログでは「URL」「openapi.json のパス」「認証方式」を設定でき、「接続を確認」で疎通を確かめられます。認証方式には API キーを使う方法のほか、システムユーザーのセッション資格情報を転送する方法があります。
- 無効にしている接続は行が薄く表示されます。

**接続の追加・編集も、画面右下の「保存」を押すまで永続化されません。**

## つまずきやすいところ

- **設定が保存されない** — この画面の変更は右下の「保存」を押すまで反映されません。ツールサーバーの接続も同じです。
- **新規登録した人がログインできない** — 「デフォルトのユーザー役割」が「保留中」になっていると、管理者が「ワークスペース > ユーザー」で役割を「ユーザー」に変えるまで使えません。
- **ログインが頻繁に切れる** — 「JWT 有効期限」を確認してください。これは操作している間は
  切れず、手を止めてからの時間で切れます (共有の端末で席を離れたときにログイン画面へ戻すための設定です)。
