# ファイルの添付と参照

この文書は、チャットにファイルや画像を添付する方法と、そのチャットで使われたファイルを
あとから開く方法の説明です。

## どこにあるか

- **添付する** — チャット画面下部の入力欄の左端にある「+」ボタン。
  ドラッグ＆ドロップ、クリップボードからの貼り付けでも添付できます。
- **チャットで使われたファイルを見る** — 画面右上のフォルダのアイコン。
  押すと右側に「チャット内ファイル」のパネルが開きます。

## 誰が使えるか

ファイルの添付には「ファイルアップロードを許可」の権限が必要です (既定では許可されています)。
権限が無いと「+」メニューの項目が薄く表示され、カーソルを重ねると
「ファイルをアップロードする権限がありません」と出て、押しても添付できません。

「チャット内ファイル」パネルは全員が使えます。

## 添付する方法

### 「+」メニューから選ぶ

1. 入力欄左の「+」を押します。
2. 「ファイルのアップロード」を選びます。
3. ファイル選択のダイアログでファイルを選びます (複数選択できます)。

### ドラッグ＆ドロップ

ファイルをチャット画面の上にドラッグすると、画面全体にドロップ領域の表示が出ます。
そのまま離すと添付されます。取りやめるときは `Esc` キーを押します。

### クリップボードから貼り付ける

画像をコピーした状態で入力欄に `Ctrl` + `V` (Mac は `⌘` + `V`) すると、画像として添付されます。
配備によっては、非常に長い文章を貼り付けたときに自動でテキストファイルへ変換されることがあります。

### 前に使ったファイルを添付し直す

1. 入力欄左の「+」を押します。
2. 「保存済みファイル」を選びます。
3. 「保存済みファイル」のウィンドウが開きます。上部の「ファイルを検索」で名前を絞り込めます。
4. 添付したいファイルの行を押すと右端にチェックが付きます (複数選べます)。
5. 右下の「添付 (件数)」を押します。

一覧には、ファイル名・サイズ・登録日時が並びます。件数が多いときは下部の「さらに読み込む」で続きが出ます。
該当が無いときは「ファイルがありません」と表示されます。取りやめるときは「キャンセル」を押します。

## 添付したファイルを外す

送信前であれば、入力欄の上に並んでいる添付のカードにカーソルを重ねると `×` が出ます。
押すとその添付だけ外れます。

## 添付した音声を再生する

音声ファイルの添付は、カードを押すと開くウィンドウでそのまま再生できます
(入力欄の上のカードでも、送信後のメッセージに付いたカードでも同じです)。
マイクで入力したときに付く録音 (「[音声入力と読み上げ](06_voice.md)」) も、ここで聞き直せます。

## チャットで使われたファイルを開く

1. 画面右上のフォルダのアイコンを押します。右側に「チャット内ファイル」のパネルが開きます。
2. 一覧からファイル名を押すと、内容のウィンドウが開きます。ここからダウンロードもできます。
3. パネル右上の `×` で閉じます。

このパネルには、**自分が添付したファイルだけでなく、応答の中で生成されたファイルも含まれます**。
フォルダのアイコンには件数のバッジが付きます (0 件のときはバッジが出ません)。
1 件も無いときは「このチャットにファイルはまだありません」と表示されます。

## うまくいかないときに出るメッセージ

| 表示                                                | 意味と対処                                                                     |
| --------------------------------------------------- | ------------------------------------------------------------------------------ |
| 「ファイルをアップロードする権限がありません。」    | 添付が許可されていないグループに属しています。管理者に相談してください。       |
| 「空のファイルはアップロードできません。」          | 中身が 0 バイトのファイルです。                                                |
| 「ファイルサイズが上限 (〇〇 MB) を超えています。」 | 配備で決められた上限を超えています。分割するか、内容を絞ってください。         |
| 「一部のモデルは画像入力をサポートしていません」    | 画像を読めないモデルが選ばれています。画像を扱えるモデルに切り替えてください。 |
| 「対応していないファイル形式です。」                | その形式は受け付けられません。                                                 |

## 注意点

- 添付できるファイルの種類・サイズの上限は配備ごとに管理者が設定します。上の制限に当たった場合は
  管理者に確認してください。
- チャットを削除しても、添付したファイル自体はワークスペースの「ファイル」に残ります。
