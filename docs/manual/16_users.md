# ワークスペース: ユーザー

この文書は、利用者アカウントとグループ、権限を管理する画面の説明です。

## どこにあるか

左サイドバー > ワークスペース > 「ユーザー」

## 誰が使えるか

**管理者のみ**です。管理者以外にはタブが表示されません。

## 画面の構成

左に「ユーザー」「グループ」の 2 つの縦タブがあります。

## 「ユーザー」タブ

### 一覧

上部に「ユーザーを追加」ボタンと検索ボックス (「検索」) があります。検索は名前とメールアドレスの部分一致です。一覧は 20 件ずつのページ送りです。

| 列 | 内容 |
|---|---|
| 「名前」 | プロフィール画像と名前 |
| 「役割」 | 「管理者」「ユーザー」「保留中」「無効」のいずれか |
| 「メールアドレス」 | ログインに使うメールアドレス |
| 「最終活動」 | 最後に利用した時点からの経過 |
| 「作成日時」 | アカウントの作成日 |

列の見出しをクリックすると並べ替わり、もう一度押すと昇順と降順が入れ替わります。

サーバー側で追加の項目 (所属など) が宣言されている場合は、その列も自動的に追加され、編集画面にも入力欄が生えます。

行の右端に吹き出しのアイコン (「チャット」) が出ている場合、押すとその利用者のチャット一覧が開きます。管理者によるチャット閲覧が有効になっている配備でのみ表示されます。

**行のどこをクリックしても編集画面 (「ユーザーを編集」ダイアログ) が開きます。** 一覧に削除のボタンはありません。

### 役割 (ロール)

| 役割 | 意味 |
|---|---|
| 「保留中」 | 登録直後の状態。承認されるまで利用できません |
| 「ユーザー」 | 通常の利用者 |
| 「管理者」 | ワークスペースのすべてのタブを扱えます |
| 「無効」 | すべての操作が遮断されます。ログインすると無効化の案内が出ます |

**利用者アカウントの完全な削除はできません。** 利用をやめさせたいときは役割を「無効」にします。チャットの記録を保全するための仕様です。

### ユーザーの追加・編集

「ユーザーを追加」または行のクリックで、単一のダイアログが開きます。新規作成のときだけ上に「フォーム」「CSVインポート」の 2 つのタブが出ます。

#### 「フォーム」

| 項目 | 備考 |
|---|---|
| 「役割」 | 「保留中」「ユーザー」「管理者」「無効」から選びます。**自分自身の役割は変更できません** |
| 「名前」 | 必須 |
| 「メールアドレス」 | 必須。**自分自身のメールアドレスは変更できません** |
| 「パスワード」/「新しいパスワード」 | 新規作成時は「パスワード」、編集時は「新しいパスワード」。編集で空欄のままにすると現状のままです |
| 追加項目 | サーバー側で宣言されている場合にのみ表示されます |

#### 「CSVインポート」

CSV ファイルを選んでまとめて登録します。

- 1 行目は見出しとして読み飛ばされます。
- 各行は **Name, Email, Password, Role** の 4 列の順です。
- Role は `admin` / `user` / `pending` のいずれかです。
- 画面に用意されているテンプレートファイルへのリンクからひな形をダウンロードできます。
- 形式が合わない行はその行だけエラーになり、他の行の登録は続きます。

## 「グループ」タブ

グループは、複数の利用者をまとめて権限を与えるための仕組みです。1 人が複数のグループに所属でき、**権限は所属するすべてのグループの合成 (どれか 1 つで許可されていれば許可)** になります。

### 一覧

上部に「グループを作成」ボタンと検索ボックス (「検索」) があります。表には「名前」と所属人数 (「ユーザー」列) が出ます。行のクリックで編集ダイアログが開きます。

グループが 1 つも無いときは「グループでユーザーをまとめ、権限を割り当てます。」と表示されます。

### グループの作成

「グループを作成」を押すと「ユーザーグループを追加」ダイアログが開きます。入力するのは「グループ名」だけです。「作成」を押すと追加されます。

### グループの編集

行のクリックで開きます。上部にグループ名の入力欄があり、その場で変更できます。左に「ユーザー」「権限」の 2 つの縦タブがあります。

- **「ユーザー」** — 検索欄で絞り込み、チェックボックスで所属を切り替えます。所属している人が上に並びます。**管理者は一覧に出ません** (グループに入れる必要がないためです)。
- **「権限」** — 後述の権限一覧です。

左下の「削除」でグループを削除でき、右下の「保存」で変更を確定します。

### 「既定の権限」

グループ一覧の下に、常時「既定の権限」が表示されています。ここは**「user」ロールの全ユーザーに適用されます**。どのグループにも属していない利用者の基準になります。

変更したら、その下の「保存」を押してください。

## 権限の一覧

グループの「権限」タブと「既定の権限」で、同じ項目を設定します。

### 「チャット権限」

| 項目 | 意味 | 既定 |
|---|---|---|
| 「ファイルアップロードを許可」 | チャットにファイルを添付できる | オン |
| 「チャット削除を許可」 | 自分のチャットを削除できる | オン |
| 「チャット編集を許可」 | 自分のチャットを編集できる | オン |
| 「チャット共有を許可」 | 自分のチャットの共有リンクを発行できる | オン |
| 「共有チャットの複製を許可」 | 共有されたチャットを自分の側に複製できる | オフ |

### 「機能」

| 項目 | 意味 | 既定 |
|---|---|---|
| 「スキル編集者」 | ワークスペースの「スキル」タブに入れるようになります。全スキルを閲覧でき、非公開のスキルを作成できます。編集できるのは自分のスキルだけで、公開範囲の変更は管理者専用です | オフ |

## つまずきやすいところ

- **自分の役割やメールアドレスが変更できない** — 自分自身に対しては、この 2 つの入力欄が無効になります。別の管理者に変更してもらってください。
- **ユーザーを削除できない** — 削除はできません。役割を「無効」にしてください。
- **グループのメンバー一覧に管理者が出てこない** — 意図した仕様です。管理者はグループに関係なくすべての操作ができます。
- **権限を変えたのに反映されない** — グループ編集ダイアログでは右下の「保存」、既定の権限では一覧下の「保存」を押す必要があります。
