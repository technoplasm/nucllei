# 音声入力・読み上げ・音声通話

この文書は、声でメッセージを入力する方法、応答を音声で読み上げさせる方法、
および音声通話の使い方の説明です。

## どこにあるか

- **音声入力** — チャット画面下部の入力欄の右側にあるマイクのアイコン (「音声を録音」)。
- **読み上げ** — 各応答の下に並ぶボタン列のスピーカーのアイコン (「読み上げ」)。
- **音声通話** — 入力欄の右側、送信ボタンの左に出るヘッドホンのアイコン (「コール」)。

## 誰が使えるか

音声入力と読み上げは、その機能が有効になっている配備であればログインしている全員が使えます。
無効な配備ではアイコンそのものが表示されません。

音声通話のボタンは、**「設定」→「チャット」→「Call(音声通話)を有効にする」をオンにした人にだけ**
表示されます (既定はオフ)。加えて、音声入力と読み上げの両方が有効な配備である必要があります。

## マイクが使えるのは HTTPS のときだけです

ブラウザは、**`https://` で開いているページ (と `localhost`) でしかマイクを使わせません**。
これはブラウザ側の決まりで、設定では変えられません。

`http://` で開いていると、マイクと音声通話のボタンが押せない状態になり、
「マイクの利用には HTTPS 接続が必要です。」と表示されます。
このときは、アドレスバーの `http://` を **`https://`** に書き換えて開き直してください。
それ以外は同じ画面です。

配備によっては `https://` で開いたときに証明書の警告が出ることがあります。
その場合の進み方は、配備ごとの案内に従ってください。
読み上げ (スピーカーのアイコン) はマイクを使わないので、`http://` のままでも利用できます。

## 声でメッセージを入力する

1. 入力欄の右側のマイクのアイコンを押します。
2. ブラウザがマイクの使用許可を尋ねてきたら、許可します。
3. 入力欄が録音の表示に変わり、波形と経過時間 (`0:12` のような表示) が出ます。
4. **話している間、文が区切れるたびに文字起こしされて入力欄に入っていきます。**
   話がひと区切りついて静かになったところが区切りです。
5. 話し終えたら、右のチェックのボタンを押します。最後の区間が文字起こしされて完了します。
6. 内容を直してから送信できます。

区切りと判定するまでの待ち時間は「設定」→「チャット」→「ボイス」の
「読み取り猶予」で変えられます (既定は 4 秒)。考えながら話していて途中で区切られてしまうときは
長くしてください。逆に、短くすると文字が早く出ます。

やめたいときは左の `×` を押します。ただし、**そこまでに入力欄へ入った文章は残ります**
(消したいときは入力欄で消してください)。

マイクのアイコンは、モデルが応答している間は表示されません。応答が終わってから使ってください。

### うまくいかないときに出るメッセージ

| 表示 | 意味 |
| --- | --- |
| 「マイクの利用には HTTPS 接続が必要です。」 | `http://` で開いています。下の「マイクが使えるのは HTTPS のときだけです」を参照してください。 |
| 「マイクへのアクセスが拒否されました」/「マイクへのアクセス時に権限が拒否されました: ...」 | ブラウザでマイクの使用が許可されていません。ブラウザの設定で許可してください。 |
| 「音声認識エラー: ...」 | 音声の認識中に問題が起きました。もう一度お試しください。 |

## 応答を読み上げさせる

1. 読み上げたい応答の下にあるスピーカーのアイコンを押します。
2. 準備中はアイコンがくるくる回り、再生が始まると停止のアイコンに変わります。
3. 途中で止めたいときは、もう一度押します。

## 音声通話を使う

### 準備

1. 「設定」→「チャット」を開きます。
2. 「ボイス」の「Call(音声通話)を有効にする」をオンにします。

これで、入力欄が空のときに送信ボタンの左にヘッドホンのアイコンが出るようになります。

### 通話する

1. ヘッドホンのアイコンを押します。
2. ブラウザがマイクの使用許可を尋ねてきたら、許可します。
3. 通話画面が開きます。画面下の表示で、いまの状態が分かります。

| 表示 | 状態 |
| --- | --- |
| 「聞き取り中...」 | こちらの発話を待っています。そのまま話してください。 |
| 「思考中...」 | 応答を作っています。 |
| 「タップで中断」 | 読み上げ中です。画面を押すと読み上げを止められます。 |

4. カメラのアイコンを押すと映像も送れます。複数のカメラがある場合は「カメラを切り替え」で選べます。
   映像をやめるときは映像左上の `×` (「カメラを停止」) を押します。
5. 通話を終えるときは、右下の閉じるボタンを押します。

読み上げの途中でも声をかけて割り込めるようにしたい場合は、
「設定」→「チャット」→「通話中に音声の割り込みを許可」をオンにします。

### 通話が始まらないとき

| 表示 | 意味 |
| --- | --- |
| ボタンが薄く表示され押せない | `http://` で開いています。`https://` で開き直してください (上記)。 |
| 「メディアデバイスへのアクセスが拒否されました」 | ブラウザでマイク (またはカメラ) の使用が許可されていません。 |
| 「Web STT エンジン使用時は通話機能を利用できません」 | この配備の音声認識の方式では通話が使えません。管理者に確認してください。 |

## 注意点

- ブラウザがマイクやカメラを使うには、`https://` で開いたうえで、使用が許可されている
  必要があります。ブラウザのアドレスバーの鍵アイコンなどから許可状況を確認できます。
- 音声通話は、入力欄に文字や添付がある間はボタンが出ません。入力欄を空にしてください。
