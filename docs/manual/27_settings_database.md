# ワークスペース > 設定: データベース

この文書は、設定の書き出し・取り込みと、データベース・全チャットの書き出しを行う画面の説明です。

## どこにあるか

左サイドバー > ワークスペース > 「設定」 > 「データベース」

## 誰が使えるか

**管理者のみ**です。管理者以外には「設定」タブ自体が表示されません。

## この画面の性質

この画面には「保存」ボタンがありません。**ボタンを押した時点で操作が実行されます。**

書き出されるファイルには、サーバーの設定や利用者のチャット内容が含まれます。取り扱いには十分注意してください。

## 操作一覧

| ボタン | 内容 |
|---|---|
| 「設定をJSONファイルからインポート」 | JSON ファイルを選ぶと、その内容でサーバーの設定を上書きします |
| 「設定をJSONファイルでエクスポート」 | 現在のサーバー設定を `config-<数字>.json` という名前で保存します |
| 「データベースをダウンロード」 | データベースのファイルをそのままダウンロードします |
| 「すべてのチャットをエクスポート (すべてのユーザー)」 | 全利用者のチャットを `all-chats-export-<数字>.json` という名前で保存します |

「データベースをダウンロード」と「すべてのチャットをエクスポート (すべてのユーザー)」は、配備の設定で管理者による書き出しが無効になっている場合には表示されません。

## 操作手順

### 設定を書き出す

1. 「設定をJSONファイルでエクスポート」を押します。
2. ブラウザのダウンロード先に JSON ファイルが保存されます。

### 設定を取り込む

1. 「設定をJSONファイルからインポート」を押します。
2. ファイル選択ダイアログで、書き出しておいた JSON ファイルを選びます。
3. 取り込みに成功すると、成功のメッセージが出ます。

## つまずきやすいところ

- **確認ダイアログが出ない** — この画面のボタンは確認なしで実行されます。特に設定の取り込みは現在の設定を上書きするので、実行前に一度書き出してバックアップを取っておくことをおすすめします。
- **ダウンロードのボタンが見当たらない** — 配備の設定で管理者による書き出しが無効にされている可能性があります。
