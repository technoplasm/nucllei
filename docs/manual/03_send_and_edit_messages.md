# メッセージの送信・編集・再生成・分岐

この文書は、チャット画面下部の入力欄からメッセージを送る操作と、送ったあとにできること
(編集・やり直し・枝分かれの行き来) の説明です。

## どこにあるか

- **入力欄** — チャット画面の下部。プレースホルダーは今の送信キーの設定 (「Ctrl+Enter で送信」か
  「Enter で送信」) を示します。スマートフォンなどのタッチ端末では「メッセージを送信」です
  (まだ何も送っていない新しいチャットでは「今日はどのようにお手伝いしましょうか？」)。
- **メッセージごとの操作ボタン** — 各メッセージの下に並ぶ小さなアイコンの列。
  最後のメッセージでは常に表示され、それより上のメッセージではカーソルを重ねると現れます。

## 誰が使えるか

送信・再生成はログインしている全員が行えます。**メッセージの編集** (自分が送ったメッセージ・応答の両方) は、
管理者が「チャット編集を許可」を切っているグループではボタンが出ません (既定では許可されています)。

## メッセージを送る

1. 入力欄に文章を書きます。
2. 送信ボタン (右端の上向き矢印) を押します。

送信ボタンにカーソルを重ねると、いま `Enter` キーがどう働くかが表示されます。

| 現在の設定               | 表示                                  |
| ------------------------ | ------------------------------------- |
| Ctrl+Enter で送信 (既定) | 「Ctrl+Enter で送信 / Enter で改行」  |
| Enter で送信             | 「Enter で送信 / Shift+Enter で改行」 |

切り替えは、入力欄左の「+」ボタン →「Enter キーの動作」で、その場で行えます
(バッジには `Enter` を押したときの動作が「改行」または「送信」と出ます)。
同じ設定は「設定」→「チャット」→「Enter キーの動作」にもあります。

長い文章を書くと、入力欄は自動で縦に伸びます (一定の高さで止まり、以降は中がスクロールします)。

## 応答中の操作

- モデルが応答している間、送信ボタンは**停止ボタン**に変わります。押すと生成を打ち切ります。
  入力欄にカーソルがある状態で `Esc` キーを押しても止まります。
- 応答を待っている間は「準備中...」、ツールの結果を受けて続きを作っている間は
  「結果を処理中...」と表示されることがあります。
- 画面を上にスクロールして最新の行から離れると、入力欄の上に**下向き矢印のボタン**が出ます。
  押すと最下部に戻り、以降は自動で追従するようになります。

## 応答に付いている操作ボタン

応答メッセージの下には、左から次のボタンが並びます (配備や状況により出ないものもあります)。

| ボタン                              | 働き                                                                                         |
| ----------------------------------- | -------------------------------------------------------------------------------------------- |
| 鉛筆 (「編集」)                     | 応答の文面を直し、「コピーとして保存」で新しい枝として残します。元の応答は書き換わりません。 |
| 四角が重なったアイコン (「コピー」) | 応答の本文をクリップボードにコピーします。                                                   |
| スピーカー (「読み上げ」)           | 応答を音声で読み上げます。読み上げ中はもう一度押すと止まります。                             |
| `i` (「生成情報」)                  | 使用トークン数などの生成情報をカーソルを重ねて表示します。                                   |
| 丸に三角 (「続きの応答」)           | 途中で切れた応答の続きを作らせます。最後の応答にだけ出ます。                                 |
| 回転する矢印 (「再生成」)           | 同じ質問でもう一度応答を作り直します。                                                       |
| 行末の数字                          | このターンの所要時間と生成速度 (例: `20秒 · 141 tok/s`)、およびコンテキスト使用量。          |

自分が送ったメッセージの下には「編集」「コピー」が並びます。

メッセージを 1 つだけ消す操作はありません (会話の履歴は積み重ねるだけで、消せない作りです)。
会話ごと消したいときは、サイドバーの各チャットの「…」→「削除」を使ってください。

## 送ったメッセージを編集する

1. 自分のメッセージの下の鉛筆アイコンを押します。文面が編集できる状態になります。
2. 直したら、次のいずれかを押します。

| ボタン         | 結果                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 「送信」       | 直した文面で**新しい枝**を作り、そのままモデルに送り直します。元の文面と応答は枝として残ります。 |
| 「キャンセル」 | 編集をやめて元に戻します。                                                                       |

送ったメッセージをその場で書き換える操作はありません。この製品は会話の履歴を「積み重ねるだけ (追記のみ)」
として扱うためです。文面を直したいときは「送信」で新しい枝として送り直してください。

編集中は `Ctrl` + `Enter` (Mac は `⌘` + `Enter`) で「送信」、`Esc` で「キャンセル」になります。

入力欄が空のときに `↑` キーを押すと、直前の自分のメッセージの編集が開きます。

## 枝分かれ (ブランチ) をたどる

「再生成」したり、メッセージを編集して「送信」したりすると、同じ位置に**複数の枝**ができます。
元の内容は消えず、行き来できます。

枝があるメッセージの操作ボタンの左端に `1/2` のような表示が出ます。

- `<` `>` で前後の枝に切り替えます。
- 数字の部分をダブルクリックすると番号を直接入力して移動できます。

入力欄が空のときに `Ctrl` + `R` (Mac は `⌘` + `R`) を押すと、最後の応答を再生成します。

## 応答の一部を選んで聞き直す (「質問」/「解説」)

応答の本文をマウスでドラッグして選択すると、選択範囲のすぐ下に小さなボタンが 2 つ出ます。

| ボタン   | 働き                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| 「質問」 | 入力欄が開きます。選択した部分について聞きたいことを書いて `Enter` (または右の矢印) を押します。 |
| 「解説」 | 「この部分をもっと詳しく説明して」という質問を、その場で送ります。                               |

答えは会話には入らず、その場に小さな吹き出しとして表示されます。
答えが出そろうと右下に「追加」ボタンが出ます。押すと、そのやり取りが会話の続きとして書き加わります。
「追加」を押さずに他の場所をクリックするか `Esc` キーを押すと、吹き出しは閉じて会話には残りません。

このボタンは、**応答が完了しているとき**にだけ出ます。共有リンクの閲覧画面では出ません。

## 応答の中に出てくるブロック

応答の本文には、次のような折りたたみブロックが混ざることがあります。見出しを押すと開閉します。

| 見出しの例                                       | 中身                                           |
| ------------------------------------------------ | ---------------------------------------------- |
| 「3.1秒間の思考」/「〇秒 思考中...」             | モデルが答えを組み立てる過程 (思考)。          |
| 「Toolの使用 **〇〇**」/「**〇〇** を実行中...」 | ツールの呼び出しと、その引数・結果。           |
| 「agent session ...」                            | 別のセッションに切り出して実行された調べもの。 |
| 「システムによる自動挿入」                       | 利用者ではなくシステムが会話に差し込んだ通知。 |

いずれも既定では閉じた状態で表示されます (「設定」→「チャット」→「思考・ツール実行を展開」で変えられます)。
開いたブロックの下辺には「閉じる」と「すべて閉じる」があり、「すべて閉じる」を押すと
その応答内のブロックをまとめて畳めます。

コードのブロックには、右上に「展開」/「折りたたむ」と「コピー」が付きます。

## 注意点

- 送ったメッセージそのものを消すことはできません。編集も再生成も**枝として積み重なる**仕組みで、
  元の内容は履歴に残ります。
- 「続きの応答」は最後の応答に対してだけ使えます。
