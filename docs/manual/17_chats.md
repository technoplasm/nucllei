# ワークスペース: チャット

この文書は、サーバー上のすべてのチャットを横断して一覧・絞り込みする画面の説明です。

## どこにあるか

左サイドバー > ワークスペース > 「チャット」

## 誰が使えるか

**管理者のみ**です。管理者以外にはタブが表示されません。

利用状況の把握、共有されているチャットの点検、削除済みチャットの確認に使います。特定の利用者 1 人分のチャットだけを見たいときは、「ワークスペース > ユーザー」の一覧で行の右端にある吹き出しのアイコンからも開けます。

## 画面の上部

検索ボックス (「チャットの検索」) は**チャットのタイトル**の部分一致です。入力を止めると自動で絞り込まれます。

その下に絞り込みが並びます。

| 項目     | 選べる値                                             | 備考                                       |
| -------- | ---------------------------------------------------- | ------------------------------------------ |
| 利用者   | 「全ユーザー」または個別の利用者                     | 括弧内はその人のチャット件数               |
| モデル   | 「全モデル」または個別のモデル                       | 括弧内はそのモデルのチャット件数           |
| 削除済み | 「削除済みを含む」「削除済みを除く」「削除済みのみ」 | 既定は「削除済みを含む」                   |
| 共有     | 「共有を含む」「共有なしのみ」「共有中のみ」         | 既定は「共有を含む」                       |
| 日付範囲 | 開始日と終了日                                       | 「更新日時」に対する範囲で、両端を含みます |

## 一覧の項目

| 列           | 内容                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 「タイトル」 | タイトルと状態の札、その下に本文の冒頭                                                                                   |
| 「ユーザー」 | 所有者の名前                                                                                                             |
| 「モデル」   | 使われたモデル                                                                                                           |
| 「ターン数」 | やりとりの回数                                                                                                           |
| 「ファイル」 | 添付ファイルの数 (0 件のときは `-`)                                                                                      |
| 「トークン」 | 記録されている入力トークン数。マウスを乗せると入力・出力の内訳と文脈長に対する割合が出ます。記録の無い古いチャットは `-` |
| 「更新日時」 | 最終更新の日時。見出しのクリックで昇順・降順が入れ替わります                                                             |

タイトルの横に付く札は次のとおりです。

- **「共有」** — 共有リンクが発行されています
- **「アーカイブ済み」** — 所有者がアーカイブしています
- **「ピン留め済み」** — 所有者がピン留めしています
- **「削除済み」** (赤) — 削除されています

一覧の下に「さらに読み込む」が出ているときは、まだ表示されていないチャットがあります。並び順は「更新日時」で固定です (向きだけ切り替えられます)。

## チャットを開く

行をクリックすると本文が開きます。開き方は行によって違います。

- **自分のチャットで、削除されていないもの** — 通常のチャット画面で開きます。編集もできます。
- **他の利用者のチャット、および削除済みのチャット** — 共有ビューで開きます。閲覧のみです。

## 共有リンクを操作する

行の右端にある共有のアイコンを押すと、共有の設定ダイアログが開きます。ここから共有リンクの発行・更新・解除ができます。削除済みのチャットにはこのアイコンは出ません。

共有リンクは**そのチャットの、共有した (または更新した) 時点のスナップショット**を見せるものです。リンクを作った後に送ったメッセージは、リンクを更新するまで共有されません。閲覧できるのはログイン済みの利用者だけです。

## つまずきやすいところ

- **削除したはずのチャットが一覧に出てくる** — 既定の絞り込みが「削除済みを含む」だからです。「削除済みを除く」に切り替えてください。チャットの削除は記録を残す削除で、行そのものは残ります。
- **自分の削除済みチャットも共有ビューで開く** — 削除済みのチャットは通常のチャット画面からは取得できないため、自分のものでも共有ビューで開きます。
- **タイトル以外の内容で検索したい** — この画面の検索はタイトルだけが対象です。
- **利用者一覧に出てくる吹き出しアイコンが無い** — 管理者によるチャット閲覧が無効になっている配備では表示されません。
