# 設定 — 「インターフェース」タブ

この文書は、ユーザー設定ウィンドウの「インターフェース」タブにある項目の説明です。
チャット画面の見た目 (吹き出しの形、画面の幅、文字の流れる向きなど) を切り替えます。

## どこにあるか

サイドバーの「設定」(または `Ctrl` + `.`) でウィンドウを開き、左側のタブから「インターフェース」を選びます。

## 誰が使えるか

ログインしている全員。変更は自分の画面にだけ効きます。

## 項目

| 項目 | 意味 | 既定 |
| --- | --- | --- |
| 「ランディングページモード」 | 新しいチャットを開いたときの最初の画面。「デフォルト」は中央に大きなあいさつと入力欄、「チャット」は会話画面と同じ配置。 | デフォルト |
| 「チャットバブルUI」 | 自分の発言を吹き出しで表示するかどうか。オフにすると本文と同じ幅の平文になります。 | オン |
| 「チャットで「あなた」の代わりにユーザー名を表示」 | 自分の発言の名前欄に「あなた」ではなく自分の名前を出します。**「チャットバブルUI」をオフにしたときだけ表示される項目**です。 | オフ |
| 「ワイドスクリーンモード」 | 会話と入力欄の横幅の制限を外し、画面いっぱいに広げます。 | オフ |
| 「チャットの方向」 | 文字の流れる向き。「自動」「LTR」(左から右)「RTL」(右から左) から選びます。 | 自動 |
| 「通知音」 | いま画面に出していないチャットで応答が終わったとき、画面右下に出る通知に合わせて音を鳴らすかどうか。 | オン |

いずれも、切り替えた時点ですぐ反映されます。「保存」ボタンはありません。

## 操作手順

1. 「設定」→「インターフェース」を開きます。
2. 変えたい項目のスイッチを押す、または選択欄から値を選びます。
3. ウィンドウを閉じると、チャット画面に反映されているのが確認できます。

## 注意点

- 「チャットで「あなた」の代わりにユーザー名を表示」は、「チャットバブルUI」がオンの間は
  一覧に現れません。見当たらないときは、まず「チャットバブルUI」をオフにしてください。
- 「チャットの方向」は、日本語や英語のように左から右へ書く言語では「自動」のままで問題ありません。
- 応答完了を OS の通知として出すかどうかは、「一般」タブの「デスクトップ通知」で設定します。
  こちらの「通知音」は、画面右下に出る通知に音を添えるかどうかだけの設定です。
- いずれの通知も、**そのチャットを画面に出していないとき**に出ます。開いているチャットの
  応答が終わっても通知は出ません。
