# ユーザー設定の開き方とタブ構成

この文書は、自分専用の設定 (「設定」ウィンドウ) をどこから開くか、どのタブに何があるか、
そして管理者向けの「ワークスペース」の設定とは何が違うかの説明です。

## どこにあるか

開き方は 3 通りあります。

- サイドバーの「設定」
- ユーザーメニュー (サイドバー最下部の自分の名前、または画面右上のプロフィール画像) の「設定」
- キーボードの `Ctrl` + `.` (Mac は `⌘` + `.`)

「設定」というタイトルのウィンドウが開きます。右上の `×` で閉じます。

## 誰が使えるか

ログインしている全員が使えます。ここでの変更は**自分の画面にだけ**効きます。
他の人の見え方は変わりません。

## タブ構成

ウィンドウの左側 (画面が狭いときは上側) にタブが並びます。

| タブ | 内容 |
| --- | --- |
| 「一般」 | テーマ・言語・デスクトップ通知。 |
| 「インターフェース」 | 画面の見た目 (チャットの表示形式、画面幅など)。 |
| 「チャット」 | チャットの操作感 (Enter キーの動作、折りたたみの既定、音声通話の表示など)。 |
| 「データ」 | チャットの取り込み・書き出し、アーカイブ、全件削除。 |
| 「アカウント」 | 名前・プロフィール画像・パスワード・API キー。 |
| 「ライセンス」 | このソフトウェアのバージョンとライセンス表記。 |

## 保存のされ方

- 「一般」「インターフェース」「チャット」の各項目は、**切り替えた時点ですぐ保存**されます。
  「保存」ボタンはありません。
- 「アカウント」タブだけは、名前やプロフィール画像を変えたあと**右下の「保存」を押す**必要があります。
  パスワードの変更はその中の専用のボタンで確定します。
- 「データ」タブは、その場で実行する操作 (取り込み・書き出し・削除) が並ぶ場所です。

## 「ワークスペース」の設定との違い

サイドバーの「ワークスペース」にも「設定」というタブがありますが、**別物です**。

| | ユーザー設定 (このウィンドウ) | ワークスペースの「設定」 |
| --- | --- | --- |
| 対象 | 自分の画面だけ | 配備全体 |
| 使える人 | 全員 | 管理者のみ |
| 例 | テーマ、Enter キーの動作 | 添付ファイルの上限など、全員に効く設定 |

モデルの中身 (システムプロンプト、割り当てるツールやスキル、生成のパラメータ) を変えるのも
ワークスペース側で、管理者の作業です。ユーザー設定からモデルの挙動は変えられません。

## 注意点

- 設定はアカウントに紐づいて保存されるため、別の端末で同じアカウントにログインしても引き継がれます。
  ただし「一般」タブの「テーマ」と「言語」は、使っているブラウザごとに保存されます。
- 一部の項目は、配備の状態によって効かないことがあります (例: 音声機能が無効な配備では、
  「Call(音声通話)を有効にする」をオンにしても通話ボタンは出ません)。
