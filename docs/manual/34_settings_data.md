# 設定 — 「データ」タブ

この文書は、ユーザー設定ウィンドウの「データ」タブにある操作の説明です。
自分のチャットをファイルとして書き出す・読み込む、アーカイブ済みの一覧を開く、
全件をまとめてアーカイブ / 削除する、といったまとめて行う操作が並びます。

## どこにあるか

サイドバーの「設定」(または `Ctrl` + `.`) でウィンドウを開き、左側のタブから「データ」を選びます。

## 誰が使えるか

ログインしている全員が使えます。対象は**自分のチャットだけ**です。
なお「すべてのチャットを削除」は、管理者が「チャット削除を許可」を切っているグループでは実行できません。

## 項目

| 項目                                 | 働き                                                            |
| ------------------------------------ | --------------------------------------------------------------- |
| 「チャットをインポート」             | 書き出した `.json` を読み込み、自分のチャットとして復元します。 |
| 「チャットをエクスポート」           | 自分の全チャットを 1 つの `.json` ファイルに書き出します。      |
| 「チャット記録」                     | アーカイブ済みチャットの一覧を開きます。                        |
| 「すべてのチャットをアーカイブする」 | 自分の全チャットをアーカイブします。                            |
| 「すべてのチャットを削除」           | 自分の全チャットを削除します。                                  |

## 操作手順

### 全チャットを書き出す

1. 「チャットをエクスポート」を押します。
2. `chat-export-<数字>.json` というファイルがダウンロードされます。

### 書き出したファイルを読み込む

1. 「チャットをインポート」を押します。
2. ファイル選択のダイアログで `.json` を選びます。
3. 読み込みが終わると、サイドバーの一覧に追加されます。

読み込めない形式のときは「チャットをインポートできません」と表示されます。

### アーカイブ済みの一覧を開く

「チャット記録」を押すと、アーカイブ済みチャットの一覧ウィンドウが開きます。
個別のアーカイブ解除・削除、全件の解除、全件の書き出しがここでできます。

### 全件をアーカイブする / 削除する

1. 「すべてのチャットをアーカイブする」または「すべてのチャットを削除」を押します。
2. その場で「よろしいですか？」という確認に変わります。
3. チェックのアイコンで実行、`×` のアイコンで取りやめます。

## 注意点

- 「すべてのチャットを削除」は**自分の全チャットが対象**です。個別に消したいときは、
  サイドバーの各チャットの「…」から削除してください。
- 削除の前に「チャットをエクスポート」で控えを取っておくと安全です。
- アーカイブは一覧から隠すだけで、内容は残ります。消したくないものはアーカイブを使ってください。
