# 画面の全体像

この文書は、ログインしてから使うことになる各画面 (サイドバー・チャット領域・上部バー・ワークスペース・設定) が
どこにあり、それぞれ何をする場所なのかを示す地図です。個々の操作手順は、それぞれの章で説明します。

## ログイン

ブラウザで本システムの URL を開くと、まずサインイン画面が表示されます。

1. 「メールアドレス」と「パスワード」を入力します。
2. 「サインイン」を押します。
3. ログインに成功すると「ログインしました。」と表示され、チャット画面に移動します。

ログイン方法は配備によって異なり、次のいずれか (または複数) が表示されます。

- メールアドレスとパスワードによるサインイン
- 「LDAP で続行」/「メールで続行」の切り替えボタン (LDAP 認証が有効な配備のみ)
- 「Google で続行」などの外部アカウントによるサインイン (該当の連携が有効な配備のみ)
- 「アカウントを作成」からの新規登録 (新規登録が許可されている配備のみ)

ログインしたのに使い始められない場合、次の画面が出ることがあります。

| 表示                   | 意味                                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| 「アカウント承認待ち」 | 登録は済んでいるが、管理者による有効化を待っている状態です。「再確認」を押すと状態を取り直せます。 |
| 「アカウント無効」     | 管理者によってアカウントが無効化されています。管理者に連絡してください。                           |

## チャット画面 (ログイン後の既定の画面)

ログイン後の画面は、大きく次の 3 つの領域に分かれています。

### 1. 左のサイドバー

上から順に、次のものが並びます。

| 項目                | 内容                                                                                                                                                                                                                                                         |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 製品名とアイコン    | クリックするとトップ (新しいチャットの入力画面) に戻ります。                                                                                                                                                                                                 |
| メニューアイコン    | サイドバーの表示・非表示を切り替えます。                                                                                                                                                                                                                     |
| 「新しいチャット」  | 新しい会話を始めます。                                                                                                                                                                                                                                       |
| 「ワークスペース」  | ファイルやモデルなどの管理画面に移動します。                                                                                                                                                                                                                 |
| 「設定」            | ユーザー設定のウィンドウを開きます。                                                                                                                                                                                                                         |
| 「モデル」          | 自分が使えるモデルの一覧です (使えるモデルが 1 つだけのときは出ません)。名前を押すと、そのモデルを選んだ状態で新しいチャットが始まります。行にカーソルを重ねると右端に鉛筆のアイコンが出ますが、これはモデル編集画面へのリンクで、管理者にだけ表示されます。 |
| 「ピン留め済み」    | ピン留めしたチャットのまとまりです。ピン留めが 1 件も無いときは表示されません。                                                                                                                                                                              |
| チャット履歴        | 「今日」「昨日」「前の7日間」「前の30日間」、それより前は同じ年なら「8月」のような月の見出し、年が違えば「2025」のような年の見出しで、更新日ごとに区切られて新しい順に並びます。下までスクロールすると続きが読み込まれます。                                 |
| 自分の名前 (最下部) | 押すとユーザーメニューが開きます。                                                                                                                                                                                                                           |

サイドバー最下部のユーザーメニューには「設定」「アーカイブ済みチャット」、
「ワークスペース」、「サインアウト」があります。

狭い画面 (スマートフォンなど) では、サイドバーは既定で閉じています。画面左端から右へスワイプすると開き、
左へスワイプすると閉じます。

### 2. 中央のチャット領域

- **上部バー** — 左端にサイドバーの開閉ボタン (サイドバーを閉じているときのみ)、その右に**モデルセレクタ**
  (現在選ばれているモデル名。押すとモデル一覧が開きます)。右端には次のボタンが並びます。

  | ボタン                 | 働き                                                                                                     |
  | ---------------------- | -------------------------------------------------------------------------------------------------------- |
  | 「…」                  | 共有・ダウンロード・コピーのメニューを開きます (そのチャットにメッセージが 1 件以上あるときだけ出ます)。 |
  | フォルダのアイコン     | 右側に「チャット内ファイル」のパネルを開きます。ファイルがあるときは件数のバッジが付きます。             |
  | 四角とペンのアイコン   | 新しいチャットを始めます (サイドバーを閉じているときのみ)。                                              |
  | 太陽 / 月のアイコン    | ライトモードとダークモードを切り替えます。                                                               |
  | 自分のプロフィール画像 | ユーザーメニューを開きます。                                                                             |

  管理者がアイドルタイムアウト (無操作が続くと自動でログアウトする設定) を有効にしている場合は、右上のボタンの
  並びの左端 (「…」の左) に、自動ログアウトまでの残り時間がリング (円) と時間 (例: `12:34`) で出ます。
  普段は隠れていて (場所は空いたままです)、そこにカーソルを重ねると現れます。残りが設定時間の半分を切ると
  常に表示され、1/4 を切ると黄色、1/8 を切ると赤になります。
  リングを押すか、何か操作 (キー入力・クリック・タップ・ホイールでのスクロール) をすると残り時間は元に戻ります。
  カーソルを重ねるだけでは戻りません。複数のタブで開いていても残り時間は共通で、どれか 1 つで操作すれば
  すべてのタブで戻ります。この表示はワークスペースの画面にも出ます (上部メニューの右端)。

- **会話の本文** — 自分が送ったメッセージと、モデルの応答が上から順に並びます。応答の中には、
  思考の過程やツールの実行結果が折りたたまれたブロックとして混ざることがあります。

- **入力欄 (画面下部)** — メッセージを書いて送る場所です。左端の「+」ボタンからファイル添付などの
  メニューを開き、右端の上向き矢印で送信します。入力欄の右上には現在のコンテキスト使用量、
  左上にはバックグラウンドタスクの状況が、それぞれ表示されることがあります。
  コンテキスト使用量は、応答の生成中はモデルの思考 (reasoning) も含めた量 (`IN` = 入力、`OUT` = 出力)、
  応答が終わると次のターンへ持ち越す量 (思考の分は次のターンに送られないので除く) を表示します。
  思考の多い応答のあとで数字が小さくなるのはこのためです。送信した直後、最初の値が届くまでは「…」と出ます。

新しいチャットを開いたばかりのときは、本文の代わりに大きなあいさつ (「こんにちは、〇〇 さん」)
またはモデル名と説明が表示され、その下に入力欄と「提案」(モデルに設定されたプロンプト例) が並びます。

### 3. 右のパネル (必要なときだけ)

上部バーのフォルダのアイコンを押すと、右側に「チャット内ファイル」のパネルが開きます。
音声通話を開始したときも、この領域に通話画面が表示されます。パネルの左端をドラッグすると幅を変えられます。

## ワークスペース

サイドバーの「ワークスペース」、またはユーザーメニューの「ワークスペース」から開きます。
上部にタブが並び、権限に応じて表示されるタブが変わります。

| タブ                                                         | 見える人                               |
| ------------------------------------------------------------ | -------------------------------------- |
| 「モデル」「ツール」「拡張」「ユーザー」「チャット」「設定」 | 管理者のみ                             |
| 「スキル」                                                   | 管理者、またはスキル編集の権限を持つ人 |
| 「ファイル」                                                 | ログインしている全員                   |

権限の無いタブの URL を直接開いた場合は、チャット画面に戻されます。

## 設定 (ユーザー設定)

自分の使い勝手を変える設定は、ワークスペースではなく**設定ウィンドウ**にあります。開き方は 3 通りです。

- サイドバーの「設定」
- ユーザーメニュー (自分の名前 / プロフィール画像) の「設定」
- キーボードの `Ctrl` + `.` (Mac は `⌘` + `.`)

「一般」「インターフェース」「チャット」「データ」「アカウント」「ライセンス」の 6 つのタブがあります。

## キーボードショートカット一覧の出し方

画面が広いとき、チャット画面の右下すみに小さな `?` ボタンがあります。押すと
「キーボードショートカット」のウィンドウが開きます。`Ctrl` + `/` (Mac は `⌘` + `/`) でも開けます。
