# ワークスペース: スキル

この文書は、モデルに読み込ませる手順書 (スキル) を作成・編集する画面の説明です。

## スキルとは

スキルは、**モデルに必要なときだけ読み込ませる Markdown の手順書**です。「この作業はこう進める」「この書式で書く」といった手順をまとめておき、モデル側が説明文を見て必要と判断したときに読み込みます。

呼び出し方は 2 通りあります。

- モデルが自分で判断してスキル一覧から読み込む
- 利用者がチャット入力欄で `/スキル ID` と入力して起動する

どちらも、そのモデルの「資格」(Capabilities) で「スキル」が有効になっていて、かつそのスキルがモデルに割り当てられている場合にだけ働きます。割り当ては「ワークスペース > モデル」の編集画面で行います。

スキルがツールを連れてくる仕組み (遅延ロード)、モデルが説明文を手がかりに選ぶこと、`/` 起動が効く 3 条件は「スキルの遅延ロード」(`19_lazy_loading.md`) にまとめてあります。ツール・拡張との違いは「ツール・スキル・拡張の違い」(`18_mechanisms.md`) を参照してください。

## どこにあるか

左サイドバー > ワークスペース > 「スキル」

## 誰が使えるか

**管理者、または「スキル編集者」権限を持つ人**です。「スキル編集者」権限は「ワークスペース > ユーザー」のグループ権限、または既定の権限で与えます。

役割によってできることが違います。

| 操作 | 管理者 | スキル編集者 |
|---|---|---|
| 一覧を見る・中身を読む | すべて | すべて |
| 新規作成 | できる | できる (必ず非公開で作られます) |
| 内容の編集 | すべて | 自分が作ったものだけ |
| 公開範囲の変更 | できる | **できない** (アイコンは表示のみ) |
| 削除 | すべて | 自分が作ったものだけ |
| ツールを紐づけたスキルの作成・更新 | できる | **できない** |

この権限の説明は「ワークスペース > ユーザー」の「グループ」側 (グループの「権限」タブ、および「既定の権限」) に「スキル編集者は全スキルを閲覧でき、非公開スキルを作成できます。編集できるのは自分のスキルのみで、共有設定は管理者専用です。」として出ます。**このスキル画面には出ません。**

## 一覧画面

上部に「スキルを作成」ボタンと検索ボックス (「スキルを検索」) があります。検索はスキル ID の部分一致です。

カードには次が並びます。

| 位置 | 意味 |
|---|---|
| 名前 (太字) | 表示名。カードのどこをクリックしても編集画面が開きます |
| 2 行目 | `/スキル ID` と説明 |
| 地球 / 鍵のアイコン | 公開範囲 (「公開」/「非公開」)。管理者はクリックで変更でき、それ以外は表示のみ |
| ごみ箱のアイコン | 「削除」。自分のスキル (管理者はすべて) にだけ出ます |

公開範囲のアイコンから開くダイアログは、**閉じた時点で保存されます**。

## 作成・編集画面

「スキルを作成」またはカードのクリックで開きます。

| 項目 | 意味 |
|---|---|
| 「名前」 | 表示名。必須です |
| 「ID」 | `/` に続けて入力します。チャット入力欄で `/この ID` と打つと起動します。**英数字とハイフンのみ**使えます。新規作成時は名前から自動生成されます |
| 「説明」 | **モデルがこのスキルを選ぶための説明**です。空欄にするとモデルには公開されません (利用者が `/コマンド` で起動することはできます) |
| 「ツール」 | このスキルと一緒に使えるようにするツール。**管理者にだけ表示されます** |
| 「公開範囲」 | 「公開」/「非公開」。**管理者にだけ表示されます** |
| 「スキルの内容」 | 手順書の本文。Markdown のエディタで編集します。空では保存できません |

本文の下に「変数は次のように波括弧で書きます: {{変数}}」という案内があります。差し込みたい箇所は `{{` と `}}` で囲みます。

自分が編集できないスキル (他の人が作ったスキルをスキル編集者が開いた場合) では、「保存」が押せず「閲覧のみ(編集できるのは自分のスキルだけです)」と表示されます。

## ID を変更したときの注意

編集画面で「ID」を書き換えて保存しようとすると、「ID を変更しますか？」という確認が出ます。

**ID の変更は「古い ID の削除 + 新しい ID での作成」として行われます。** その結果、

- 他の項目からこのスキルへの割り当てや参照は外れます (モデルへの割り当ても外れます)
- 設定値などの項目別設定はリセットされます

## つまずきやすいところ

- **モデルがスキルを使ってくれない** — 「説明」が空だとモデルには公開されません。またモデル側の「資格」で「スキル」が有効になっていること、そのモデルにスキルが割り当てられていることを確認してください。
- **`/コマンド` で起動できない** — ID に英数字とハイフン以外の文字が入っていないか、そのモデルにスキルが割り当てられているかを確認してください。
- **公開範囲のアイコンを押しても何も起きない** — 変更できるのは管理者だけです。スキル編集者には現在の状態が表示されるだけです。
- **ツール付きスキルが保存できない** — ツールを紐づけたスキルの作成・更新は管理者だけの操作です。画面にも「tool 紐づき skill の作成/更新は admin のみ可能です。」と出ます。
