# 設定 — 「チャット」タブ

この文書は、ユーザー設定ウィンドウの「チャット」タブにある項目の説明です。
送信キーの割り当て、タイトルの自動生成、折りたたみの既定、音声通話の表示、チャットの背景画像を切り替えます。

## どこにあるか

サイドバーの「設定」(または `Ctrl` + `.`) でウィンドウを開き、左側のタブから「チャット」を選びます。

## 誰が使えるか

ログインしている全員。変更は自分の画面にだけ効きます。

## 「チャット」セクションの項目

| 項目                                             | 意味                                                                                                 | 既定              |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ----------------- |
| 「Enter キーの動作」                             | 「Enter で送信」か「Ctrl+Enter で送信」かを選びます。                                                | Ctrl+Enter で送信 |
| 「タイトル自動生成」                             | チャットのタイトルを自動で付けるかどうか。オフのときは最初に送った文面がそのままタイトルになります。 | オン              |
| 「整形済みテキストをコピー」                     | 応答をコピーするときに、書式付きでコピーするかどうか。オフのときは素のテキストになります。           | オフ              |
| 「応答本文のコードブロックを展開」               | 応答に含まれるコードのブロックを、最初から開いた状態で表示するかどうか。                             | オン              |
| 「思考・ツール実行を展開」                       | 思考のブロックとツール実行のブロックを、最初から開いた状態で表示するかどうか。                       | オフ              |
| 「ブランチの切り替え時にボタンをスクロールする」 | 枝分かれ (`1/2` の矢印) を切り替えたときに、自動で最下部までスクロールするかどうか。                 | オン              |
| 「触覚フィードバック」                           | 応答が届くたびに端末を短く振動させます (振動に対応した端末のみ)。                                    | オフ              |

## 「ボイス」セクションの項目

| 項目                                                | 意味                                                                                                                                                   | 既定   |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| 「Call(音声通話)を有効にする」                      | 入力欄に音声通話 (コール) のボタンを出すかどうか。                                                                                                     | オフ   |
| 「通話中に音声の割り込みを許可」                    | 読み上げの途中でも、こちらが話しかけて割り込めるようにするかどうか。                                                                                   | オフ   |
| 「読み取り猶予 — 無音がこの秒数続いたら区切る(秒)」 | 音声入力で、話が途切れてから文字起こしに送るまでの待ち時間。長くすると考えながら話しても途中で区切られません。短くすると文字が早く出ます。0.5〜30 秒。 | 4 秒   |
| 「最短の発話区間(秒)」                              | これより短い音は文字起こしに送りません。咳や物音で細切れの文字が入るのを防ぎます。0〜5 秒。長くすると「はい」のような短い返事も落ちます。              | 0.3 秒 |

## 「ファイル」セクション

見出しだけがあり、現在このセクションに設定項目はありません。
添付できるファイルの上限などは配備側 (管理者) の設定です。

## 「チャットの背景画像」

セクションの下、区切り線の下にある独立した項目です。チャット画面の背景に画像を敷きます。

1. 「アップロード」を押します。
2. 画像ファイル (GIF / WebP / JPEG / PNG) を選びます。
3. 設定されると、ボタンの表示が「リセット」に変わります。押すと背景画像を外せます。

対応していない形式を選ぶと「対応していないファイル形式です。」と表示されます。

## 操作手順

1. 「設定」→「チャット」を開きます。
2. 変えたい項目のスイッチを押す、または選択欄から値を選びます。切り替えた時点で保存されます。

## 注意点

- 「Enter キーの動作」は、チャット入力欄の「+」メニューからもその場で切り替えられます。
  いまどちらになっているかは、送信ボタンにカーソルを重ねると表示されます。
- 「Call(音声通話)を有効にする」をオンにしても、配備側で音声の機能が無効な場合は
  通話ボタンは出ません。
- 「読み取り猶予」と「最短の発話区間」は、音声入力と音声通話の両方に効きます。
  音声通話では、読み取り猶予がそのまま応答が返り始めるまでの待ち時間になります。
- 「思考・ツール実行を展開」をオフのままでも、応答内のブロックの見出しを押せばいつでも開けます。
