# ワークスペース: ファイル

この文書は、チャットに添付されたファイルやここから直接アップロードしたファイルを一覧・検索・共有・削除する画面の説明です。

## どこにあるか

左サイドバー > ワークスペース > 「ファイル」

## 誰が使えるか

**ログインしている利用者全員**です。ワークスペースの中で管理者以外も入れるタブは、この「ファイル」と「サンドボックス」(サンドボックスを使う配備のみ。[12a サンドボックス](12a_sandbox.md)) だけです。

見える範囲は役割によって変わります。

- **管理者以外** — 自分がアップロードしたファイルだけが見えます。
- **管理者** — 既定では自分のファイルだけが表示され、「アップロード者で絞り込み」で他の利用者のファイルも表示できます。削除済みファイルの表示・復元・実体の破棄も管理者だけの操作です。

## 画面の上部

| 要素                              | 意味                                                                                                 |
| --------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 「ファイルのアップロード」        | ファイル選択ダイアログを開きます。複数選択できます                                                   |
| 検索ボックス (「ファイルを検索」) | ファイル名の部分一致で絞り込みます                                                                   |
| 「カード表示」/「テーブル表示」   | 一覧の見せ方を切り替えます。選択はブラウザに記憶されます                                             |
| 上下矢印のアイコン                | 並び順を逆にします。ツールチップに現在の向き (「新しい順」「古い順」または「昇順」「降順」) が出ます |

その下に絞り込みの行があります。

| 項目                         | 選べる値                                         | 備考                                                                    |
| ---------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------- |
| 「並び替え」                 | 「作成日時」「最終アクセス」「名前」             | 既定は「作成日時」の新しい順                                            |
| 「グループ化」               | 「日」「月」「年」                               | 見出しで区切ります。「名前」で並べているときは表示されません            |
| 削除済みの扱い               | 「普通のファイルのみ」「削除済みのみ」「すべて」 | **管理者のみ**。既定は「普通のファイルのみ」                            |
| 「アップロード者で絞り込み」 | 利用者を選ぶと札 (チップ) が追加されます         | **管理者のみ**。札の ✕ で外します。1 人も選ばなければ自分のファイルだけ |

一覧の下に「さらに読み込む」が出ているときは、まだ表示されていないファイルがあります。

## 一覧の項目

### カード表示

- 左のサムネイル (画像ファイルは画像、それ以外は書類のアイコン) にマウスを乗せるとチェックボックスに変わります。クリックで選択します。
- 中央にファイル名、その下にサイズと日時が出ます。クリックすると内容のプレビューが開きます。
- 右側にアイコンが並びます。

### テーブル表示

「名前」「サイズ」「種類」「作成日時」「最終アクセス」の列が並びます。「名前」「作成日時」「最終アクセス」の見出しはクリックで並び替えられます。削除済みを表示しているときは「削除日時」「削除者」の列も出ます。左端のチェックボックスで行を選択でき、見出しのチェックボックスは「すべて選択」です。

### 行のアイコン

| アイコン         | 意味                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------- |
| 吹き出し         | 「関連チャット」。このファイルを参照しているチャットの一覧を開きます                  |
| 鍵 / 人 / 地球   | 現在の共有状態 (「非公開」「共有」「公開」)。押すと共有範囲の変更ダイアログが開きます |
| ゴミ箱           | 「削除」                                                                              |
| 反時計回りの矢印 | 「復元」。削除済みの行にだけ出ます (**管理者のみ**)                                   |
| 炎               | 「実体を破棄」。削除済みの行にだけ出ます (**管理者のみ**)                             |

削除済みのファイルには赤い「削除済み」の札が、実体を破棄したファイルには「実体なし」の札が付きます。実体を破棄したファイルは開けません。

## 共有範囲を変える

共有状態のアイコンを押すと「アクセス制御」ダイアログが開きます。ファイルの共有範囲は 3 段階です。

| 段階       | 意味                                       |
| ---------- | ------------------------------------------ |
| 「公開」   | 全ユーザーがアクセス可能                   |
| 「共有」   | 選択したユーザー・グループのみアクセス可能 |
| 「非公開」 | 自分だけがアクセスできます (既定)          |

「共有」を選ぶと下に入力欄 (「グループ・ユーザーを追加」) が出ます。グループ名や利用者名を入力して候補から選ぶと札として追加され、札の ✕ で外れます。

**ダイアログを閉じた時点で保存されます。** 別途の保存ボタンはありません。

## 複数のファイルをまとめて操作する

チェックボックスでファイルを選ぶと、画面下部に操作バーが出ます。

- 「N 件を選択中」 — 選択数
- 人のアイコン (「共有」) — 選択中のファイルすべてに同じ共有範囲を適用します。選択したファイルの共有範囲が揃っていればその値から、混在していれば「非公開」から始まります
- ゴミ箱 (「削除」) — 選択中のファイルをまとめて削除します
- ✕ (「選択を解除」) — 選択を解除します

選択中のファイルの行にあるアイコンを押した場合も、選択全体への一括操作になります。

削除済みのファイルには共有範囲を設定できないため、選択がすべて削除済みのときは「共有」が押せません。

## 削除と実体の破棄

- **「削除」** は取り消せる削除です。確認ダイアログには「このファイルが添付されたチャットでは「削除済み」として表示が残ります。」と出ます。行は残っており、管理者は「削除済みのみ」または「すべて」に切り替えて復元できます。
- **「実体を破棄」** は取り消せません。確認ダイアログに「中身は復元できなくなります。」と出ます。破棄後は「実体なし」の札が付き、プレビューも開けなくなります。

## つまずきやすいところ

- **他の人のファイルが見えない** — 管理者以外は自分のファイルだけが見えます。管理者でも、既定では自分のファイルだけです。「アップロード者で絞り込み」で対象を追加してください。
- **削除したファイルが一覧から消えない** — 表示条件が「削除済みのみ」または「すべて」になっていると、削除後も行が残ります。
- **共有範囲を変えたのに反映されない** — ダイアログを閉じた時点で保存されます。閉じずに画面を離れると反映されません。
- **「ファイルのアップロード」が淡色で押せない** — 所属グループで「ファイルアップロードを許可」が切られています。カーソルを重ねると「ファイルをアップロードする権限がありません」と出ます。チャットへの添付も同じ権限で制御されています。必要な場合は管理者に相談してください。
- アップロードできるファイルの上限サイズ・件数・拡張子は「ワークスペース > 設定 > ファイル」で決まっています。
