# チャットの整理 (名前の変更・ピン留め・複製・アーカイブ・削除)

この文書は、サイドバーに溜まっていくチャットを整理する操作の説明です。

## どこにあるか

- **チャット一覧** — 画面左のサイドバー。更新日ごとに「今日」「昨日」「前の7日間」「前の30日間」、
  それより前は同じ年なら「1月」「2月」…の月の見出し、年が違えば「2025」のような年の見出しで
  区切られ、新しい順に並びます。
- **チャットの検索ボックス** — サイドバーのチャット一覧の直上 (「会話を検索」)。
- **各チャットの操作メニュー** — 一覧の項目にカーソルを重ねると右端に現れる「…」。
- **アーカイブ済みの一覧** — ユーザーメニュー (サイドバー最下部の自分の名前) の「アーカイブ済みチャット」、
  または「設定」→「データ」→「アーカイブ済みチャット」。

## 誰が使えるか

自分のチャットに対する操作なので、ログインしている全員が行えます。
ただし**削除**は、管理者が「チャット削除を許可」を切っているグループでは使えません (既定では許可)。

## チャットのタイトル

最初のメッセージを送ると、タイトルは自動で付けられます。
自動生成をやめたい場合は「設定」→「チャット」→「タイトル自動生成」をオフにします。
オフのときは、**最初に送った文面がそのままタイトルになります**。

### 名前を変える

方法は 2 つあります。

- サイドバーの項目を**ダブルクリック**すると、その場で編集できる状態になります。
- 項目の「…」→「名前を変更」を選びます。

編集中は右端にチェックと `×` が出ます。チェックで確定、`×` で取りやめです。
空のタイトルは保存できず「タイトルは空文字列にできません。」と表示されます。

## 「…」メニューでできること

| 項目                          | 働き                                                  |
| ----------------------------- | ----------------------------------------------------- |
| 「ピン留め」/「ピン留め解除」 | サイドバー上部の「ピン留め済み」にまとめます。        |
| 「名前を変更」                | タイトルを編集します。                                |
| 「クローン」                  | 同じ内容のチャットをもう 1 つ作ります。元は残ります。 |
| 「アーカイブ」                | 一覧から隠します。内容は残ります。                    |
| 「共有」                      | 共有リンクのウィンドウを開きます。                    |
| 「ダウンロード」              | `.json` / `.txt` / `.pdf` で保存します。              |
| 「削除」                      | 確認のうえ削除します。                                |

## チャットを検索する

サイドバーのチャット一覧の直上にある「会話を検索」に言葉を入れると、一覧がその言葉を含むチャットだけに
絞り込まれます。**タイトルと本文の両方**が対象で、入力した文字列をそのまま含むもの (部分一致) が
新しい順に並びます。

- 入力をやめて少し待つと絞り込まれます (`Enter` ですぐに絞り込めます)。
- 絞り込み中は「ピン留め済み」と日付の見出しは出ません。該当するチャットが無いときは「該当なし」と表示されます。
- 右端の `×` または `Esc` で検索を消すと、通常の一覧に戻ります。
- 絞り込まれた項目でも「…」メニュー (名前の変更・ピン留め・アーカイブ・削除など) はそのまま使えます。

### 「チャットで調べる」

言葉を入れたあと、検索ボックスの右の「チャットで調べる」を押すと、**新しいチャット**が開き、入力欄に
「『(入れた言葉)』でチャット履歴を検索して」という文面が入ります。この時点では送信されていないので、
文面を直してから送ってください。送るとモデルが組み込みの履歴ツール (ワークスペース →「ツール」の
「組み込み」にある履歴の一覧・検索) で過去のチャットを探し、見つけた内容をまとめて答えます。
「あのとき何を聞いたか」「どのチャットだったか」のように、単語の一致だけでは探しにくいときに使います。
(モデルの設定で履歴ツールが使えない場合は、通常の会話として応答します。)

## ピン留め

よく戻るチャットは「ピン留め」しておくと、サイドバー上部の「ピン留め済み」にまとまります。
「ピン留め済み」の見出しを押すと開閉できます (開閉の状態は次回も保たれます)。

サイドバーのチャットを「ピン留め済み」の中へドラッグしても、ピン留めできます。

## アーカイブ

読み終わったチャットを一覧から外したいときはアーカイブします。削除ではないので内容は残ります。

1. 項目の「…」→「アーカイブ」を選びます。
2. サイドバーの一覧から消えます。

### アーカイブしたチャットを見る・戻す

1. サイドバー最下部の自分の名前を押し、「アーカイブ済みチャット」を選びます。
2. アーカイブ済みのチャットが「名前」「作成日時」の一覧で表示されます。上部の「チャットの検索」で
   タイトルを絞り込めます。
3. 各行の右端にあるアイコンで、「チャットをアーカイブ解除」または「チャットを削除」ができます。
4. 下部の「アーカイブ済みチャットをすべて解除」で全件を戻せます (確認が出ます)。
   「アーカイブ済みチャットをすべてエクスポート」で全件を 1 つの `.json` に保存できます。

1 件も無いときは「これまでにアーカイブされた会話はありません。」と表示されます。

## 削除

1. 項目の「…」→「削除」を選びます。
2. 「チャットを削除しますか？」の確認が出ます。「削除対象:」に対象のタイトルが表示されるので、
   間違いがなければ確定します。

いま開いているチャットは、`Ctrl` + `Shift` + `Backspace` (または `Delete`) でも削除できます。

削除したチャットの共有リンクは同時に解除されます。

## `Shift` キーを押しながらのショートカット操作

`Shift` キーを押したままサイドバーの項目にカーソルを重ねると、「…」の代わりに
**アーカイブ**と**削除**のアイコンが直接現れます。メニューを開かずに素早く処理できます。

## 子セッションの表示

サイドバーで選んでいるチャットが、調べものを別セッション (agent session) に切り出していた場合、
その項目の下に子セッションが 1 段下げて並びます。名前を押すと、その子セッションを開けます。
実行中の子には回転するアイコンが付きます。

## 注意点

- サイドバーの一覧は下へスクロールすると続きが読み込まれます。
- アーカイブ済み一覧の「チャットの検索」は、その一覧の中で**タイトル**を絞り込むためのものです。
  本文まで探すにはサイドバーの「会話を検索」を使ってください (アーカイブ済みは対象外です)。
- 「クローン」で作ったチャットは元のチャットとは別物です。片方を消してももう片方は残ります。
