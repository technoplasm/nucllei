# スキルの呼び出しと、ツール実行の見え方

この文書は、チャット入力欄から「スキル」と「レシピ」を呼び出す方法と、モデルが「ツール」を実行したときに
画面がどう見えるかの説明です。スキルとツールの作成・管理はワークスペース側で行います。レシピはチャットの中で
モデルに頼んで作ります ([19a 仕組み: レシピ](19a_recipes.md))。

用語の整理:

- **スキル** — あらかじめ用意された指示のまとまり。`/` で始まるコマンドで利用者が呼び出します。
- **レシピ** — 利用者が残した手順。スキルと同じく `/` で呼び出せます。
- **ツール** — モデルが必要に応じて自分で呼び出す機能。利用者がチャットの中で選ぶことはありません。
  どのツールが使えるかは、選んでいる**モデル**に管理者が割り当てています。

この 2 つと「拡張 (Function)」が何を分担しているかは「ツール・スキル・拡張の違い」
(`18_mechanisms.md`)、下に出てくる「ツールを読み込みました」の札が何をしているのかは
「スキルの遅延ロード」(`19_lazy_loading.md`) にあります。

## どこにあるか

- **スキル・レシピの呼び出し** — チャット入力欄の**先頭**で `/` を入力します。
- **ツールの実行結果** — 応答の中に折りたたみブロックとして表示されます。
- **バックグラウンドで動いている処理** — 入力欄の左上に出るチップ「バックグラウンドタスク」。

## 誰が使えるか

スキルは、**選んでいるモデルに紐づいていて、かつ自分に公開されているもの**だけが候補に出ます。
同じチャットでもモデルを切り替えると候補が変わります。

レシピは、選んでいるモデルの「能力」で「レシピ」がオンのとき ([11 モデル](11_models.md)) に、
個人のレシピ・所属しているグループのレシピ・全体のレシピが候補に出ます (管理者でも、所属していない
グループのレシピは出ません)。サンドボックスのある配備でだけ出ます。

候補が 1 件も無いときは、`/` を打っても一覧が出ません。

## スキル・レシピを呼び出す

1. 入力欄が空の状態で `/` を入力します。一覧が入力欄の上に出ます。並びは「個人のレシピ」「グループのレシピ」
   「全体のレシピ」「スキル」の順です。
2. 続けて文字を打つと絞り込まれます (例: `/kan`)。打った文字で始まるものが先、途中に含むものが後に並びます。
3. `↑` `↓` で選び、`Enter` または `Tab` で確定します。マウスでクリックしても選べます。
4. 入力欄の先頭が `/スキルのID ` または `/レシピの名前 ` に置き換わります。そのうしろに、頼みたい内容を
   続けて書きます。
5. 送信します。

一覧の各行には、スキルなら ID (`/〇〇`)・名前・説明、レシピなら名前 (`/〇〇` — フォルダの名前)・題・説明が
並びます。グループのレシピには、右にグループ名が出ます。警告のあるレシピ ([19a](19a_recipes.md) の「警告」)
は「警告: …」が添えられますが、選べます。

送信すると、応答の先頭にスキルなら `load_skill`、レシピなら `load_recipe` のブロックが出ます。モデルが
自分で読み込んだときと同じ内容です。一覧から選ばずに `/名前` と打って送っても同じです。

### 選べない行

同じ名前のものがいくつもあるときは、使われるもの以外が灰色になり、選べません。灰色の行には理由が出ます。

| 理由                                            | どういうときか                                                                                                                                          |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| スキル「〇〇」が使われる                        | 同じ名前のスキルがある。スキルが先で、同じ名前のレシピはどの置き場のものも使われません                                                                  |
| 個人のレシピが使われる                          | 同じ名前の個人のレシピがある。狭い置き場が先です (個人 → グループ → 全体)                                                                               |
| グループ「〇〇」のレシピが使われる              | 同じ名前のグループのレシピがある。グループ同士では、グループ名の順で先のものが使われます                                                                |
| 個人のレシピが先 (壊れているので何も呼ばれない) | 使われるはずの個人のレシピが壊れている。グループ・全体の同じ名前のレシピにも代わりません (グループのレシピが先のときは「グループ「〇〇」のレシピが先」) |
| 壊れている: …                                   | レシピの書式に誤りがある ([19a](19a_recipes.md) の「壊れている」)。モデルに直してもらってください                                                       |
| 名前に空白があるので / では呼べない             | レシピの名前に空白がある。`/` では呼べないので、「〇〇のレシピで」と頼んでください                                                                      |

個人のレシピを直すか消すと、次の置き場のレシピが使われるようになります。

上下キーは灰色の行を飛ばします。打った名前とちょうど同じ名前の行があれば、それが最初に選ばれます。

### 注意点

- スキル・レシピが働くのは、**入力全体の 1 行目の行頭にある `/` だけ**です。文の途中に `/` を書いても
  呼び出しにはなりません (一覧も出ません)。
- 選んでもテンプレート文が丸ごと挿入されるわけではありません。入るのは `/スキルのID ` や `/レシピの名前 ` だけです。
- レシピの `/名前` が働くのは、送った発言のときだけです。応答を作り直すと、もう一度読み込まれます。

## 別のモデルに 1 回だけ聞く (`@`)

入力欄で `@` を入力するとモデルの一覧が出ます。選ぶと入力欄の上に「〇〇 と会話中」と出て、
その送信 1 回だけそのモデルが応答します。`Esc` キーか、その表示の `×` でやめられます。

## ツールが実行されたときの見え方

モデルがツールを使うと、応答の中に折りたたみのブロックが現れます。

| 状態     | 見出し                                                                                                                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 実行中   | 「**ツール名** を実行中...」(くるくる回るアイコン付き。進捗や経過秒数が出ることがあります)                                                                                                                                                      |
| 完了     | 「Toolの使用 **ツール名**」(緑のチェックと所要時間)                                                                                                                                                                                             |
| 呼び直し | 黄色の回る矢印と「呼び直し」。ツールに渡した値 (検索語が空・形の誤りなど) が違っていました。多くの場合、モデルがすぐに呼び直します                                                                                                              |
| 失敗     | 黄色の「!」と「失敗」。時間切れ・接続先に届かない・接続先がエラーを返した・同時に動かせる数の上限など、ツールがうまく動けませんでした。実行した Python やコマンドがエラー・時間切れで終わったときもこれで、出力とエラーの内容は Result に出ます |
| 該当なし | 黄色の虫めがねと「該当なし」。ツールは動きましたが、「見つからなかった」「大きすぎて読めなかった」のように答えがありませんでした                                                                                                                |
| 規約違反 | 赤の禁止マークと「規約違反」。モデルがツールの呼び出し方の決まりを破りました (使えないツールを呼んだ・必要な引数を付けなかったなど)。ツールは実行されていません                                                                                 |
| エラー   | 赤の「×」と「エラー」。ツールやサーバー自体の不具合・設定の誤りです。続くときは管理者に連絡してください                                                                                                                                         |

黄色の 3 つ (呼び直し・失敗・該当なし) はよくあることで、多くの場合モデルが自分で次の手を打ちます。
赤 (規約違反・エラー) が出たときは、モデルの挙動やサーバーに問題があるかもしれません。
どの場合も、理由は Result に書かれています。

見出しを押すと中身が開き、次のものが見られます。

- **引数** — ツールに渡された値。何も渡していないときは「引数なし」と表示されます。
- **Result** — ツールが返した結果。テキスト・表・コードなど、ツールによって形が変わります。
  呼び直し・失敗・該当なし・規約違反・エラーのときは、何が起きたかの説明 (「ERROR: …」で始まる文) がここに出ます。
  「次の手:」より後ろはモデルへの指示です。

開いたブロックの下辺には「閉じる」と「すべて閉じる」があります。

スキルを読み込むツール (`load_skill`) が動いた場合は、ブロックを開くとそのスキルの本文が表示されます。
そのスキルがツールを連れてくるときは、本文の下に「ツールを読み込みました」という札と、使えるように
なったツール名が並びます (ツールを連れてこないスキルでは、この札は出ません)。
スキルに読み込み時に動かすツールがあるとき ([13 スキル](13_skills.md)) と、レシピを読み込んだとき
(`load_recipe`。[19a レシピ](19a_recipes.md)) は、中で読んだもの・動かしたものが 1 行ずつ並び、行を押すと
その中身が開きます。警告やエラーがあると、ブロックの見出しに三角の印と件数が付きます。

これらのブロックを既定で開いた状態にしたいときは、「設定」→「チャット」→「思考・ツール実行を展開」を
オンにします。

## 調べものが別セッションに切り出されたとき

長い調べものは、別の「agent session」として実行されることがあります。この場合、応答の中に
枠付きのブロックが出て、次のものが並びます。

| 表示                                        | 意味                                                                               |
| ------------------------------------------- | ---------------------------------------------------------------------------------- |
| 「agent session」または実行に使われた設定名 | このブロックが 1 つの子セッションであること                                        |
| 「実行中...」                               | まだ動いていること                                                                 |
| 緑のチェック / 赤の警告                     | 正常終了 / エラー                                                                  |
| 停止アイコン                                | その子セッションを止めます (動いている間だけ表示)。                                |
| 枝分かれのアイコン (「フォーク」)           | その子セッションを自分のチャットとして複製し、続きを自分で操作できるようにします。 |
| 右上向き矢印 (「開く」)                     | その子セッションを 1 つのチャットとして開きます。                                  |

子セッションが動いている間は、ブロックが自動で開き、見出しが「子を起動しました」→「考え中」→「回答中」と
変わって、子の考えている様子と回答がその場に流れます。終わると、普段の開閉の設定 (「設定」→「チャット」→
「思考・ツール実行を展開」) に戻ります。動いている途中でブロックを閉じると、見出しは「実行中...」になります。

ブロックを開くと、子セッションに渡された指示と、そのやり取りが読めます。ページを再読み込みしても、
子セッションの記録 (と「フォーク」「開く」) はそのまま表示されます。
親のチャットに渡された答えが短縮されている場合は「回答は親チャットへ切り詰めて渡されました」と出ます。

「agent session を読み込めませんでした」と出た場合は、その子セッションを読み出せなかった状態です。

子セッションを同時に動かせる数には、サーバー全体で上限があります (ほかの利用者の分も数えます。上限は
配備によって異なります)。上限に達しているときもエラーにはならず、**枠が空くのを順番に待ってから**動きます。
待っている間は、ツールのブロックの見出しに「サブエージェントの枠が空くのを待っている (2 番目、15 秒)」の
ように待ちの順番と待った秒数が出ます。混み合っているときは、答えが返るまでいつもより時間がかかることがあります。
待てる時間にも上限があり (配備の設定によります。既定では子セッション 1 回に許される時間とほぼ同じです)、
それを過ぎると子セッションは起動せず、そのツールは「失敗」になります。多くの場合、モデルが自分で続きを処理します。

## バックグラウンドで動いている処理

時間のかかるツールは、応答を待たずに裏で走ることがあります。このとき、入力欄の左上に
「バックグラウンドタスク」というチップが件数付きで出ます。押すと一覧が開きます。

| 表示                                   | 意味                                                                                        |
| -------------------------------------- | ------------------------------------------------------------------------------------------- |
| 「実行中...」                          | まだ動いています。右の停止ボタンで個別に止められます。                                      |
| 「完了」                               | 終わりました。結果は会話に届きます。                                                        |
| 「呼び直し」「失敗」「該当なし」       | 黄色のアイコン付き。ツールの見出しと同じ意味です (上の「ツールが実行されたときの見え方」)。 |
| 「規約違反」「エラー」                 | 赤のアイコン付き。ツールの見出しと同じ意味です。                                            |
| 「停止済み」                           | 停止操作で止めました。                                                                      |
| 「サーバー再起動により失われました」   | サーバーの再起動で追跡できなくなりました。やり直してください。                              |
| 「自動再開を停止中(上限に達しました)」 | 自動で続きを進める回数が上限に達しています。こちらから次のメッセージを送ると再開します。    |

応答の生成を止めても、バックグラウンドで動いている処理は止まりません。止めたいときは、
この一覧から個別に停止してください。

## システムが差し込んだメッセージ

バックグラウンド処理の結果などが届くと、会話の中に「システムによる自動挿入」という
ラベルの付いたメッセージが現れることがあります。「展開」「折りたたむ」で中身を出し入れできます。
