# 操作マニュアル (原稿)

**エンドユーザー向けの操作マニュアルの一次原稿**です。日本語。nucllei の画面を、
職員・一般の利用者が読んで操作できる粒度で説明しています。

- **1 ファイル = 1 画面 / 1 設定タブ。** 各ファイルは「この文書は何か」「どこにあるか」
  「誰が使えるか」「操作」「つまずきやすいところ」の順で書かれています。例外は「仕組み」の 2 本 (`18`〜`19`) で、こちらは画面ではなく機構そのものを説明します
- **nucllei 単体の事実だけ**を書いています。特定の配備でだけ成り立つこと (接続先のアドレス、
  載せているモデル、有効にしている認証方式、上限値) は書きません。配備に依存する部分は
  「配備によって異なります」「管理者に確認してください」と逃がしてあります
- **frontmatter はありません。**`# 見出し` から始まる素の Markdown です
- **ここが一次情報源です。** LLENS (北大病院) など配備先の文書ツリーへは、ここから転記されます。
  画面を変えたときは**まずこのファイルを直し**、配備先へ転記し直してください。
  配備先で直しても次の転記で消えます

転記先の例: LLENS の cage 文書ツリー
`/医療情報システム/LLENSマニュアル/{02_チャットの基本操作,03_ワークスペース,04_ユーザー設定}`
(2026-09-04 転記。転記時に frontmatter の付与・ファイル名の日本語化・製品名の解決を行っています)

## 書くときの約束

- **画面に出ている文字列は「」で囲んで、実物と同じ表記で書く。** ボタン名・ラベル・
  エラーメッセージは利用者が画面から探す手がかりなので、言い換えない
- **配備依存のことは書かない。** 「配備によって異なります」「管理者に確認してください」に逃がす
- **できないこと・落とし穴を省かない。** 「押しても削除されない」「保存前にタブを切り替えると
  戻る」のような挙動は、書いておかないと利用者が事故る
- 製品名は本文中では `nucllei` と書く。転記先が配備の表示名に置き換える
  (画面上の表記としての `Nucllei` — ライセンスタブに出る本体名 — は固有名詞なので置き換えない)
