# ワークスペース > 設定: 接続

この文書は、推論エンジン (OpenAI 互換 API・Ollama) への接続を登録する画面の説明です。

## この画面の位置づけ

nucllei 自身はモデルを持ちません。ここで登録した接続先から素のモデルの一覧を取り込み、それを「ワークスペース > モデル」で土台 (ベースモデル) に選ぶことで、チャットで使えるモデルになります。

取り込まれた素のモデルの一覧は「ワークスペース > 設定 > モデル」で確認できます。

## どこにあるか

左サイドバー > ワークスペース > 「設定」 > 「接続」

## 誰が使えるか

**管理者のみ**です。管理者以外には「設定」タブ自体が表示されません。

## 画面の構成

「OpenAI API」と「Ollama API」の 2 つの節に分かれています。それぞれ右のスイッチで有効・無効を切り替えます。

**スイッチの切り替えは、その場で即座に反映されます。** 接続の追加と、「接続を編集」ダイアログで「保存」を押したときも、その場で反映されます。一覧の行で URL や API キーを直接書き換えたときは、右下の「保存」を押してください。

接続を削除するときは、行の歯車のアイコン (「設定」) で「接続を編集」ダイアログを開き、「削除」を押します。確認ダイアログが出るので、確定すると一覧から行が消えます。**削除は「OpenAI API」「Ollama API」のどちらの接続も、確定した時点で保存されます。** 右下の「保存」を押す必要はありません。

## 「OpenAI API」

スイッチをオンにすると「OpenAI API 接続を管理」が現れます。

- 右の「+」(「接続を追加」) で新しい接続を追加します。
- 追加済みの接続は行として並び、URL と API キーをその場で編集できます。歯車のアイコン (「設定」) から「接続を編集」ダイアログが開きます。
- 接続先がパイプラインサーバー ([26 パイプライン](26_settings_pipelines.md)) のときは、URL の欄の右端に重なった層のアイコン (ツールチップは「Pipelines」) が出ます。

「接続を追加」/「接続を編集」ダイアログの項目は次のとおりです。

| 項目                  | 意味                                                                                   |
| --------------------- | -------------------------------------------------------------------------------------- |
| 「URL」               | 接続先の API ベース URL。右のボタン (「接続を確認」) で疎通を確かめられます            |
| 有効・無効のスイッチ  | この接続を使うかどうか。無効にすると一覧の行が薄く表示されます                         |
| 「キー」              | API キー                                                                               |
| 「プレフィックス ID」 | モデル ID に付ける接頭辞。他の接続とモデル ID がぶつかるのを避けます。空欄で無効       |
| 「モデル ID」         | 取り込むモデルを限定します。**空欄にするとその接続が返すすべてのモデルを取り込みます** |

OpenAI 互換の API であれば、OpenAI 以外のサーバーにも接続できます。

## 「Ollama API」

スイッチをオンにすると「Ollama API 接続を管理」が現れます。操作の流れは「OpenAI API」と同じで、接続先の URL (例: `http://localhost:11434`) を入力します。

Ollama の接続行には API キーの欄がありません。API キーが要る接続先では、歯車のアイコン (「設定」) から「接続を編集」ダイアログを開き、「キー」に入力します。

Ollama の接続行には歯車のアイコン (「設定」) のほかに「管理」のアイコンがあり、そこからその接続に対するモデルの取得・削除を行えます。同じ操作は「ワークスペース > 設定 > モデル」の「モデルを管理」からも行えます。

## つまずきやすいところ

- **モデルが増えない** — 接続のスイッチが有効か、その接続が無効になっていないかを確認してください。反映は「ワークスペース > 設定 > モデル」で確認できます。
- **モデル ID がぶつかる** — 複数の接続で同じモデル ID が返ってくる場合は、接続の詳細ダイアログで「プレフィックス ID」を設定してください。
- **再起動したら接続が戻った** — 環境変数で決めてある設定は、再起動すると環境変数の値に戻ります ([20 一般](20_settings_general.md) の「環境変数で決めてある設定」)。
- **接続を足したのにチャットで選べない** — 接続で取り込むのは素のモデルです。チャットで使うには「ワークスペース > モデル」で「モデルを作成」し、「ベースモデル (From)」にそのモデルを選ぶ必要があります。
