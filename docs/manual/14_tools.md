# ワークスペース: ツール

この文書は、モデルが呼び出せる「ツール」を一覧・作成・編集する画面の説明です。

## ツールとは

ツールは、**モデルが会話の途中で呼び出せる Python の関数のまとまり**です。1 つのツールが複数の関数を公開でき、モデルはその中から必要な関数を選んで実行します。

ツールには 2 種類あります。

- **組み込み** — nucllei に最初から入っているツールです。編集も削除もできません。公開範囲と設定値だけ変更できます。
- **カスタム** — この画面で作った独自のツールです。

**チャット画面でツールを選ぶ仕組みはありません。** どのツールが使えるかは、モデルに割り当てられたツールで決まります。割り当ては「ワークスペース > モデル」の編集画面で行います。

スキル・拡張との違い (誰が呼ぶか、モデルから見えるか、コンテキストをどう食うか) は「ツール・スキル・拡張の違い」(`18_mechanisms.md`) にまとめてあります。スキルに紐づけたツールを必要なときだけ載せる仕組みは「スキルの遅延ロード」(`19_lazy_loading.md`) を参照してください。

## どこにあるか

左サイドバー > ワークスペース > 「ツール」

## 誰が使えるか

**管理者のみ**です。管理者以外にはタブが表示されません。

## 一覧画面

上部に「ツールを作成」ボタンと検索ボックス (「ツールの検索」) があります。検索は名前と ID の部分一致です。

組み込みのツールがある場合、一覧は「組み込み」と「カスタム」の 2 つの節に分かれます。組み込みが無い場合は見出しなしの 1 つの一覧になります。

カードには次が並びます。

| 位置 | 意味 |
|---|---|
| 名前 (太字) | 表示名。カスタムはカードのクリックで編集画面が開きます |
| 2 行目 | ツール ID と、そのツールが公開する関数名の並び |
| 地球 / 鍵のアイコン | 公開範囲 (「公開」/「非公開」)。押すと変更ダイアログが開きます |
| 歯車のアイコン | 「設定値」。そのツールが設定値を持たないときは押せず、「設定値はありません」と出ます |
| ごみ箱のアイコン | 「削除」。カスタムにだけ出ます |

**組み込みツールはカードをクリックしても編集画面は開きません。**「組み込みツールは編集できません。」というツールチップが出ます。ただし公開範囲と設定値は一覧のアイコンから変更できます。

公開範囲のアイコンから開くダイアログは、**閉じた時点で保存されます**。

### 公開範囲

| 段階 | 意味 |
|---|---|
| 「公開」 | 全ユーザーがアクセス可能 |
| 「非公開」 | 選択したユーザー・グループのみアクセス可能 |

「非公開」を選ぶと下に入力欄 (「グループ・ユーザーを追加」) が出ます。グループ名や利用者名を入力して候補から選ぶと札 (チップ) として追加され、札の ✕ で外れます。

### 設定値

歯車のアイコンから「設定値」ダイアログが開きます。ツールのコード側で宣言した設定項目 (API キー、接続先 URL、既定値など) をここで入力します。「保存」を押すと反映されます。

## 作成・編集画面

「ツールを作成」またはカスタムツールのカードのクリックで開きます。

| 項目 | 意味 |
|---|---|
| 「名前」 | 表示名。必須です |
| 「ID」 | 内部で使う識別子。必須です。新規作成時は名前から自動生成されます |
| 「説明」 | 一覧に出る短い説明。空でも構いません |
| 「公開範囲」 | 上の表と同じ 2 段階 |
| 「ツールの内容」 | Python コード。エディタで編集します |

新規作成では、`Tools` クラスの雛形があらかじめ入っています。この `Tools` クラスのメソッドが、モデルから呼べる関数になります。各メソッドには型注釈と説明 (docstring) を付けてください。説明の内容がそのままモデルへの案内になります。

「保存」を押すと、コードが自動で整形されてから保存されます。**整形できないコード (構文エラーなど) は保存されません。**

## ID を変更したときの注意

編集画面で「ID」を書き換えて保存しようとすると、「ID を変更しますか？」という確認が出ます。

**ID の変更は「古い ID の削除 + 新しい ID での作成」として行われます。** その結果、

- 他の項目からこのツールへの割り当てや参照は外れます (モデルへの割り当ても外れます)
- 設定値などの項目別設定はリセットされます

## つまずきやすいところ

- **モデルがツールを呼んでくれない** — そのモデルの編集画面でツールが割り当てられているか、公開範囲が「非公開」のときに対象の利用者が含まれているかを確認してください。
- **保存しても反映されない** — 構文エラーがあると整形の段階で止まり、保存されません。
- **組み込みツールを直したい** — できません。同等の処理を行うカスタムツールを別に作ってください。
- **外部の OpenAPI 互換ツールサーバーに繋ぎたい** — この画面ではなく「ワークスペース > 設定 > 一般」の「ツールサーバーを管理」で設定します。
