# ワークスペース > 設定: ファイル

この文書は、チャットへのファイル添付に関するサーバー全体の設定を行う画面の説明です。

## この画面の位置づけ

ここで決めた上限や制限は、利用者がチャットにファイルを添付するとき、およびワークスペースの「ファイル」タブからアップロードするときに適用されます。

「最大アップロードサイズ」は、モデルがチャットのファイルとサンドボックスの間で受け渡すとき (添付ファイルをサンドボックスに取り込む、サンドボックスで作ったファイルをチャットに添付する) の 1 ファイルあたりの上限も兼ねます。保存するとすぐに効きます。

次の 3 つには適用されません。これらの上限はサンドボックスの配備の設定 (既定 1024 MB) で、この画面からは変えられません。

- ワークスペースの「サンドボックス」タブからのアップロード・ダウンロード
- モデルが URL の中身をサンドボックスに取り込むとき
- モデルがサンドボックスのファイルを画像として見るとき (こちらは既定でさらに 25 MB が上限です)

利用者ごとの設定ではありません。個々のファイルの共有範囲や削除は「ワークスペース > ファイル」で扱います。

## どこにあるか

左サイドバー > ワークスペース > 「設定」 > 「ファイル」

## 誰が使えるか

**管理者のみ**です。管理者以外には「設定」タブ自体が表示されません。

## 設定項目

変更したら、画面右下の「保存」を押してください。

| 項目                                     | 意味                                                                                                    | 空欄にしたとき                 |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 「Attachment Function」                  | ファイルがアップロードされるたびに実行する拡張を 1 つ選びます。ファイルからテキストを取り出す役割です   | 「なし」を選ぶと無効になります |
| 「最大アップロードサイズ」               | 1 ファイルあたりの上限 (MB)。超えたファイルはアップロードされず、サンドボックスとの受け渡しもされません | 無制限                         |
| 「最大アップロード数」                   | チャットで一度に使えるファイル数の上限。超えた分はアップロードされません                                | 無制限                         |
| 「許可する拡張子」                       | 受け付ける拡張子をカンマ区切りで指定します (例: `pdf, docx, xlsx`)                                      | すべて許可                     |
| 「画像の最大長辺 (px)」                  | 長辺がこの値を超える画像は、アップロード前に縮小されます。画像の形式は保たれます                        | 縮小しません                   |
| 「長文ペーストのファイル化閾値(文字数)」 | この文字数を超える貼り付けは `.txt` の添付ファイルに変換されます                                        | 変換しません                   |

### 「Attachment Function」について

ドロップダウンには、「ワークスペース > 拡張」に登録されている **Attachment 種別の拡張**が並びます。選べるのは 1 つだけです。

Attachment の拡張を作っていない配備では、「なし」しか選べません。

設定済みの拡張が削除されている場合、その ID がそのまま選択肢として表示されます。この状態で保存しようとするとエラーになるので、有効なものか「なし」に選び直してください。

### 「許可する拡張子」の書き方

カンマ区切りで拡張子を並べます。先頭のドットは付けても付けなくても構いません (保存時に取り除かれ、小文字に揃えられます)。

## つまずきやすいところ

- **ファイルを添付できない利用者がいる** — 添付の可否は「ワークスペース > ユーザー」の権限にある「ファイルアップロードを許可」でも制御されます。この画面の設定とは別です。許可されていない利用者には、チャットの添付メニューとワークスペースの「ファイル」タブのアップロードボタンが淡色で表示され、押しても「ファイルをアップロードする権限がありません。」と案内されます。ワークスペースの「サンドボックス」タブでは「アップロード」ボタン自体が出ません。
- **添付したファイルの中身をモデルが読めない** — ファイルからテキストを取り出すのは「Attachment Function」の役割です。「なし」になっていないか確認してください。
- **保存できない** — 「Attachment Function」に、既に存在しない拡張が選ばれたままになっていないか確認してください。
