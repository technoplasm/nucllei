# ワークスペースの概要

この文書は、nucllei の管理画面である「ワークスペース」の入口・入れる人・タブ構成をまとめたものです。個々のタブの操作方法は、それぞれのタブごとの文書で説明します。

## ワークスペースとは

ワークスペースは、チャット画面の裏側を作り込むための管理画面です。チャットで選べるモデル、モデルに持たせるツールやスキル、アップロードされたファイル、利用者アカウントとその権限、サーバー全体の設定を、すべてこの一つの画面から扱います。

nucllei には「管理者パネル」という別の画面はありません。管理に関わる操作はすべてワークスペースに集約されています。

## どこにあるか

- 左サイドバーの「ワークスペース」
- 画面右上のユーザーメニューの「ワークスペース」

どちらも同じ画面 (`/workspace`) を開きます。

開いた直後に表示されるタブは、ログインしている人によって変わります。

- 管理者 → 「モデル」タブ
- 管理者以外 → 「ファイル」タブ

## 誰が使えるか

ワークスペースの入口自体は、ログインしている利用者全員に表示されます。ただし**中のタブは役割 (ロール) と権限によって出し分けられます**。

| タブ | 表示される人 |
|---|---|
| 「モデル」 | 管理者のみ |
| 「ファイル」 | ログインしている利用者全員 |
| 「スキル」 | 管理者、または「スキル編集者」権限を持つ人 |
| 「ツール」 | 管理者のみ |
| 「拡張」 | 管理者のみ |
| 「ユーザー」 | 管理者のみ |
| 「チャット」 | 管理者のみ |
| 「設定」 | 管理者のみ |

タブが表示されない画面の URL を直接開こうとした場合は、チャット画面へ戻されます。表示・非表示はあくまで導線の出し分けであり、実際の可否はサーバー側でも判定されています。

「スキル編集者」権限は、ワークスペースの「ユーザー」タブ内、「グループ」の権限設定にある「スキル編集者」スイッチで与えます。

## タブ構成

画面上部に、左から次の順でタブが並びます (表示されるものだけが並びます)。

1. **「モデル」** — チャットのモデル一覧に出すモデルを作る・編集する画面です。システムプロンプト、ツール・スキルの割り当て、公開範囲をここで決めます。
2. **「ファイル」** — アップロードされたファイルの一覧・検索・共有範囲の変更・削除を行う画面です。
3. **「スキル」** — モデルに読み込ませる手順書 (スキル) を作る・編集する画面です。
4. **「ツール」** — モデルが呼び出せるツール (Python コード) を作る・編集する画面です。
5. **「拡張」** — Filter / Attachment / Action / Pipe といったサーバー側の拡張コードを管理する画面です。
6. **「ユーザー」** — 利用者アカウントとグループ、権限を管理する画面です。
7. **「チャット」** — サーバー上の全チャットを横断して一覧・絞り込みする画面です。
8. **「設定」** — サーバー全体の設定画面です。中がさらに「一般」「接続」「モデル」「ファイル」「インターフェース」「オーディオ」「パイプライン」「データベース」のタブに分かれています。

## 覚えておきたい考え方

- **「使えるか」と「編集できるか」は別の仕組みです。** 各項目 (モデル・ツール・スキル・ファイル) には「公開範囲」があり、これは「誰がそれを使えるか」を決めます。一方「誰がその定義を編集できるか」は役割で決まっており、モデル・ツール・拡張は管理者だけが編集できます。
- **チャット側には設定を出していません。** システムプロンプトやサンプリングのパラメータは、チャット画面ではなくワークスペースの「モデル」側に集約されています。利用者がチャットのたびに挙動を変えることはできません。
- **ツールの選択もモデル側です。** 利用者がチャットの入力欄でツールを選ぶ仕組みはありません。どのツールが使えるかは、モデルに割り当てられたツールで決まります。
