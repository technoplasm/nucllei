# 設定 — 「ライセンス」タブ

この文書は、ユーザー設定ウィンドウの「ライセンス」タブに表示される内容の説明です。
このソフトウェアの名称・バージョンと、権利表記が載っています。設定を変える項目はありません。

## どこにあるか

サイドバーの「設定」(または `Ctrl` + `.`) でウィンドウを開き、左側のタブから「ライセンス」を選びます。
タブのラベルは「ライセンス」です。

## 誰が使えるか

ログインしている全員が見られます。表示だけで、操作する項目はありません。

## 表示される内容

上から順に、次のものが並びます。

| 段                       | 内容                                                                                                                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 配備の名称               | 画面左上に出ているのと同じ製品名と、そのバージョン。権利表記が設定されている配備では、その下に表記が出ます。この段は、配備で独自の名称や権利表記が設定されている場合にだけ表示されます。 |
| 「Nucllei」              | 本体の名称とバージョン、および英語の帰属表記。                                                                                                                                           |
| 「Upstream License」     | この製品のもとになったソフトウェア (Open WebUI v0.6.5、BSD-3-Clause) のライセンス全文。                                                                                                  |
| 「Third-Party Licenses」 | 配布物に同梱されているフォントのライセンス表記 (SIL Open Font License 1.1)。該当が無い場合はこの段ごと表示されません。                                                                   |

「Upstream License」「Third-Party Licenses」の見出しと、「Third-Party Licenses」の中の小見出し
「Fonts」は、日本語表示でも英語のままです。
ライセンス本文も原文のまま表示されます (ライセンス文書は翻訳せずに掲示するのが通例のためです)。

## こんなときに使う

- 問い合わせのときに、いま使っているバージョンを伝えたい。
- このソフトウェアが何をもとに作られているか、権利表記を確認したい。

バージョンは 2 か所に出ます。上段が配備の名称に対するバージョン、中段が本体 (Nucllei) の
バージョンです。問い合わせのときは、見えている両方を伝えると確実です。

## 注意点

- ここに載るのは「配布物に実体が同梱されていて表記の義務があるもの」だけです。
  内部で使っているすべてのソフトウェアが列挙されているわけではありません。
- 上段の名称・権利表記は配備ごとに異なります。設定されていない配備ではこの段が出ません。
