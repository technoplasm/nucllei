# ワークスペース > 設定: オーディオ

この文書は、音声入力 (STT: 音声をテキストにする) と読み上げ (TTS: テキストを音声にする) の設定画面の説明です。

## どこにあるか

左サイドバー > ワークスペース > 「設定」 > 「オーディオ」

## 誰が使えるか

**管理者のみ**です。管理者以外には「設定」タブ自体が表示されません。

ここで有効にした音声機能は、**利用者全員が使えます**。利用者ごとやグループごとに音声機能だけを制限する設定はありません。無効にすると、チャット画面の該当するアイコンが消えます。

## 保存の仕方

変更したら、画面右下の「保存」を押してください。ただし「テキスト音声変換エンジン」を切り替えたときは、その時点で一度保存されます。

## 「STT設定」(音声入力)

| 項目                         | 意味                                                   |
| ---------------------------- | ------------------------------------------------------ |
| 「音声入力(STT)を有効化」    | オフにすると、チャット画面の音声入力アイコンが消えます |
| 「音声テキスト変換エンジン」 | 使うエンジンを選びます                                 |

エンジンは次から選べます。選んだエンジンによって、下に出る入力欄が変わります。

| エンジン                     | 追加で入力するもの                                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| 「Whisper(ローカル)」 (既定) | 「STTモデル」— 使う whisper モデル名。右のダウンロードボタンでモデルを取得します   |
| OpenAI                       | 「API ベース URL」「API キー」「STTモデル」                                        |
| 「ウェブAPI」                | なし (ブラウザの音声認識を使います)                                                |
| Deepgram                     | 「API キー」「STTモデル」(空欄で既定のモデル)                                      |
| Azure AI Speech              | 「API キー」「Azureリージョン」「言語ロケール」(例: `en-US,ja-JP`。空欄で自動検出) |

「Whisper(ローカル)」を選んだ場合、nucllei は内部で faster-whisper を使います。モデル名を入力してダウンロードのボタンを押すと取得が始まり、完了するまでボタンは待機状態になります。

## 「TTS 設定」(読み上げ)

| 項目                         | 意味                                                   |
| ---------------------------- | ------------------------------------------------------ |
| 「読み上げ(TTS)を有効化」    | オフにすると、チャット画面の読み上げアイコンが消えます |
| 「テキスト音声変換エンジン」 | 使うエンジンを選びます                                 |

エンジンは次から選べます。

| エンジン                       | 追加で入力するもの                                                                                     |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| 「ウェブAPI」 (既定)           | 「TTSボイス」— ブラウザが持っている音声から選びます                                                    |
| 「Transformers」(「ローカル」) | 「TTSモデル」— CMU Arctic の話者埋め込み名。nucllei は SpeechT5 と CMU Arctic の話者埋め込みを使います |
| 「OpenAI」                     | 「API ベース URL」「API キー」「TTSボイス」「TTSモデル」                                               |
| 「ElevenLabs」                 | 「API キー」「TTSボイス」「TTSモデル」                                                                 |
| 「AzureAIスピーチ」            | 「API キー」「Azureリージョン」「TTSボイス」「出力形式」                                               |

### 「応答の分割」

読み上げのために、応答のテキストをどう区切って送るかを決めます。

| 値         | 意味                                 |
| ---------- | ------------------------------------ |
| 「句読点」 | 文単位で分割します                   |
| 「段落」   | 段落単位で分割します                 |
| 「なし」   | 分割せず、1 つの文字列のまま送ります |

## つまずきやすいところ

- **チャット画面に音声のアイコンが出ない** — この画面の「音声入力(STT)を有効化」「読み上げ(TTS)を有効化」を確認してください。
- **通話機能が使えない** — 「ウェブAPI」の STT エンジンを使っているときは通話機能を利用できません。別のエンジンを選んでください。
- **ボイスの一覧が空** — 「ウェブAPI」ではブラウザが持つ音声を読み込みます。ブラウザによっては読み込みに少し時間がかかります。外部エンジンの場合は、API キーが正しいか確認してください。
