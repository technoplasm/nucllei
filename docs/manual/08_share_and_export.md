# チャットの共有・ダウンロード・コピー

この文書は、1 つのチャットを他の人に見せる (共有リンク)、ファイルとして手元に保存する (ダウンロード)、
テキストとして写し取る (コピー) 操作の説明です。

## どこにあるか

- **開いているチャット** — 画面右上の「…」ボタン。
- **サイドバーの任意のチャット** — 項目にカーソルを重ねて現れる「…」。

## 誰が使えるか

共有は「チャット共有を許可」の権限がある人だけが行えます (既定では許可されています)。
権限が無いと、メニューに「共有」が出ません。ダウンロードとコピーは全員が使えます。

共有リンクを**見る**側は、**ログインしている利用者**である必要があります。ログインしていない人は
リンクを開けません。

## 共有リンクを作る

1. 「…」→「共有」を選びます。「チャットを共有」のウィンドウが開きます。
2. 説明文を読みます。まだ共有していない場合は
   「リンクを知っているログイン済みユーザーが、このチャットのスナップショットを閲覧できます。
   リンク作成後に送ったメッセージは、リンクを更新するまで共有されません。」と表示されます。
3. 「リンクを作成してコピー」を押します。リンクがクリップボードにコピーされ、
   「共有チャットURLをクリップボードにコピーしました!」と表示されます。
4. コピーされた URL を、共有したい相手に伝えます。

## 共有中のチャットを操作する

すでに共有しているチャットで「共有」を開くと、次の表示になります。

- 共有リンクが入力欄に表示されます。右のクリップボードのアイコンでコピーできます。
- 「リンクには、最後に共有・更新した時点のスナップショットが表示されます。」という説明が出ます。

| ボタン                   | 働き                                                           |
| ------------------------ | -------------------------------------------------------------- |
| 「リンクの更新とコピー」 | いまの内容でスナップショットを取り直し、リンクをコピーします。 |
| 「共有を解除」           | 共有をやめます。リンクは開けなくなります。                     |

**共有されるのは「その時点のスナップショット」です。** リンクを作ったあとに続けた会話は、
「リンクの更新とコピー」を押すまで相手には見えません。

## 共有リンクを開いたときの画面

共有リンクを開くと、タイトル・日時と会話の内容が読み取り専用で表示されます。入力欄はありません。

- チャットが見つからないときは「チャットが見つかりません」と表示されます。
- 「共有チャットの複製を許可」の権限を持つ人には、画面下部に「チャットを複製」ボタンが出ます。
  押すと、その内容が自分のチャットとして複製され、続きから会話できます。
  この権限は**既定ではオフ**なので、ボタンが出ないのが通常です。

## ダウンロードする

1. 「…」→「ダウンロード」を選びます。
2. 形式を選びます。

| 形式                              | 内容                                         |
| --------------------------------- | -------------------------------------------- |
| 「チャットをエクスポート(.json)」 | あとで読み込み直せる形式。                   |
| 「プレーンテキスト (.txt)」       | 発言者と本文だけの素のテキスト。             |
| 「PDF ドキュメント (.pdf)」       | 画面の見た目に近い形で A4 に流し込んだ PDF。 |

## 会話全体をコピーする

画面右上の「…」→「コピー」を選ぶと、会話全体がテキストとしてクリップボードにコピーされます。
成功すると「クリップボードにコピーしました。」と表示されます。

応答 1 件だけをコピーしたいときは、その応答の下にあるコピーのアイコンを使います。

## 注意点

- 共有リンクは、**そのリンクを知っているログイン済み利用者なら誰でも**開けます。
  内容に配慮が必要な会話を共有するときは、渡す相手を確認してください。
- チャットを削除すると、そのチャットの共有は自動的に解除されます。
- PDF は画面を画像として取り込んで作るため、長い会話ではファイルが大きくなります。
