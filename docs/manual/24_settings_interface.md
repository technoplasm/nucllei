# ワークスペース > 設定: インターフェース

この文書は、裏で走る補助タスク (チャットのタイトル生成など) の設定と、画面上部に出すお知らせ (バナー) を設定する画面の説明です。

## どこにあるか

左サイドバー > ワークスペース > 「設定」 > 「インターフェース」

## 誰が使えるか

**管理者のみ**です。管理者以外には「設定」タブ自体が表示されません。

## 保存の仕方

変更したら、画面右下の「保存」を押してください。

## 「タスク」の節

「タスク」は、利用者との会話とは別に、システムが裏で行う短い処理のことです。チャットのタイトルを自動で付ける処理がこれにあたります。

### 「タスクモデルの設定」

タスクに使うモデルを指定します。指定しない場合はそのチャットで使っているモデルがそのまま使われます。

| 項目               | 意味                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| 「ローカルモデル」 | チャットで使っているモデルが Ollama から来ているときに使うモデル。Ollama のモデルの中から選びます |
| 「外部モデル」     | チャットで使っているモデルが Ollama 以外 (OpenAI 互換 API など) から来ているときに使うモデル      |

どちらの選択肢も、チャットのモデル一覧に出るモデル (「ワークスペース > モデル」で作ったモデル) です。
どちらを使うかは、そのチャットで使っているモデルがどこから来ているかで決まります。両方を設定しても、1 つのチャットで使われるのは片方だけです。
「現在のモデル」を選ぶと、チャットで使っているモデルをそのまま使います。

### 「タイトル生成」

スイッチでチャットタイトルの自動生成を切り替えます。オンのときは下に「タイトル生成プロンプト」の入力欄が出ます。**空欄のままにすると既定のプロンプトが使われます。**

オフにした場合は、モデルにタイトルを考えさせる代わりに、**そのチャットの最初の発言がそのままタイトルになります**。タイトルが「新しいチャット」のまま並ぶことはありません。

利用者の側にも、自分のチャットについて同じ切り替え (ユーザー設定の「チャット」→「タイトル自動生成」、[33 チャット](33_settings_chats.md)) があります。モデルがタイトルを考えるのは、**ここと利用者の設定の両方がオンのときだけ**です。どちらかがオフなら、最初の発言がタイトルになります。

## 「UI」の節

### 「バナー」

全利用者の画面上部に出すお知らせを設定します。周知やメンテナンス予告に使えます。

- 右の「+」で行を追加します。**内容が空の行があると、それ以上は追加できません。**
- 追加した行は、「閉じることを許可」がオンの状態で始まります。
- 「種類」は必須です。種類を選んでいない行があると「保存」できません。
- 各行の構成は次のとおりです。

| 要素                                | 意味                                                                 |
| ----------------------------------- | -------------------------------------------------------------------- |
| 左のドロップダウン (「種類」)       | 「情報」「警告」「エラー」「成功」から選びます。表示の色が変わります |
| 「コンテンツ」                      | 表示する本文                                                         |
| 右のスイッチ (「閉じることを許可」) | オンにすると、利用者がバナーを閉じられます                           |
| 右端の ✕                            | その行を削除します                                                   |

## つまずきやすいところ

- **チャットのタイトルが自動で付かない** — 「タイトル生成」のスイッチを確認してください。
- **タイトル生成が重い** — 会話に使っているモデルとは別の、軽いモデルを「タスクモデルの設定」で指定できます。
- **バナーの行が増やせない** — 内容が空の行が残っています。先に内容を入力してください。
- **バナーを消せない** — 「閉じることを許可」がオフのバナーは、利用者側では閉じられません。
- **「保存」が押せない・保存されない** — 「種類」を選んでいないバナーの行がないか確認してください。
- **管理者がオンにしているのに、タイトルが最初の発言のままになる人がいる** — その人がユーザー設定で「タイトル自動生成」をオフにしています。
- **再起動したら設定が戻った** — 環境変数で決めてある設定は、再起動すると環境変数の値に戻ります ([20 一般](20_settings_general.md) の「環境変数で決めてある設定」)。
