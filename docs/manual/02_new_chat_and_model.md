# 新しいチャットを始める / モデルを選ぶ

この文書は、新しい会話を始める方法と、その会話で使うモデル (AI の種類) を選ぶ方法の説明です。

## どこにあるか

- **新しいチャット** — サイドバーの「新しいチャット」。サイドバーを閉じているときは、
  画面右上の四角とペンのアイコン。キーボードでは `Ctrl` + `Shift` + `O` (Mac は `⌘` + `Shift` + `O`)。
- **モデルセレクタ** — 画面上部中央にある、現在のモデル名と下向き矢印。押すと一覧が開きます。
- **サイドバーの「モデル」欄** — 使えるモデルが縦に並んでいます。

## 誰が使えるか

ログインしている全員が使えます。ただし、一覧に出るモデルは人によって異なります
(管理者が、部署や職種などのグループ単位で「誰がどのモデルを使えるか」を決めています)。
自分に割り当てられていないモデルは、そもそも一覧に出ません。

## 新しいチャットを始める

1. サイドバーの「新しいチャット」を押します。
2. 画面中央に、あいさつ (「こんにちは、〇〇 さん」) またはモデル名と説明が出ます。
3. 下の入力欄にメッセージを書いて送信すると、そこから会話が始まります。

最初のメッセージを送るまで、そのチャットはサイドバーの履歴に現れません。
モデルによっては、入力欄の下に「提案」としてプロンプトの例が並びます。押すとその文面が入力欄に入ります。

### 特定のモデルで始める

サイドバーの「モデル」欄でモデル名を押すと、**そのモデルを選んだ状態で新しいチャットが始まります**。
毎回同じモデルを使う場合はこちらが早道です。

## モデルを選び直す

1. 画面上部中央のモデル名を押します。
2. 一覧が開きます。上部の検索欄にモデル名の一部を打ち込むと絞り込めます。
3. 使いたいモデルの行を押すと、そのモデルに切り替わります。

検索欄のプレースホルダーは「モデルを検索」です。

一覧の各行には、モデルのアイコンと名前が並びます。名前の右に鎖のアイコンが付くのは、外部の
OpenAI 互換 API から取り込んだモデルであることを示します (ツールチップは英語のまま `External` と出ます)。
モデルに説明が設定されている場合は `i` のアイコンが付き、カーソルを合わせると説明が出ます。
該当するモデルが無いときは「結果が見つかりません」と表示されます。

### 一覧内で使えるキー操作

| キー      | 働き                             |
| --------- | -------------------------------- |
| `↓` / `↑` | 選択行を上下に動かします。       |
| `Enter`   | 選択中の行のモデルに決定します。 |

## 既定のモデルを決める

よく使うモデルを「既定」にしておくと、新しいチャットを開いたときに最初から選ばれた状態になります。

1. モデルセレクタを開きます。
2. 既定にしたいモデルの行の**右端にあるしおり (ブックマーク) のアイコン**を押します。
   チェック付きのしおりに変われば設定完了です。
3. 解除したいときは、同じアイコンをもう一度押します。

ホバーすると「デフォルトに設定」または「既定モデルを解除」と表示されます。
既定は 1 つだけです。別のモデルのしおりを押すと、そちらに付け替わります。

## 会話の途中で別のモデルに 1 回だけ聞く

入力欄で `@` を打つとモデルの一覧が出ます。選ぶと、入力欄の上に
「〇〇 と会話中」と表示され、**その送信 1 回だけ**そのモデルが使われます。
やめたいときは、その表示の右にある `×` を押すか、入力欄で `Esc` キーを押します。

## 注意点

- モデルを切り替えても、それまでの会話の内容は消えません。次の送信から新しいモデルが応答します。
- チャットごとに使えるスキルは、選んでいるモデルに紐づいています。モデルを変えると
  入力欄の `/` で出てくるスキルの顔ぶれも変わります。
- 「モデルが選択されていません」と出た場合は、モデルセレクタでモデルを選んでから送信してください。
