# ワークスペース > 設定: モデル

この文書は、接続先から取り込まれている素のモデルを一覧で確認する画面の説明です。

## 「ワークスペース > モデル」との違い

同じ「モデル」という名前ですが、扱うものが違います。

| 画面                                          | 扱うもの                                                                                 |
| --------------------------------------------- | ---------------------------------------------------------------------------------------- |
| ワークスペース > 「モデル」                   | チャットのモデル一覧に出るモデル。名前・システムプロンプト・ツール・公開範囲を設定します |
| ワークスペース > 設定 > 「モデル」 (この画面) | 接続先から取り込まれている**素のモデル**の一覧                                           |

**素のモデルは、そのままではチャットで使えません。** チャットで使うには「ワークスペース > モデル」で「モデルを作成」し、「ベースモデル (From)」に素のモデルを選びます。

この画面には、素のモデルの名前を変えたり公開範囲を設定したりする機能はありません。あくまで「どのモデルが取り込まれているか」を確かめるための一覧です。

## どこにあるか

左サイドバー > ワークスペース > 「設定」 > 「モデル」

## 誰が使えるか

**管理者のみ**です。管理者以外には「設定」タブ自体が表示されません。

## 一覧

上部に検索ボックス (「モデル検索」) があります。名前と ID の部分一致です。一覧は名前順に並びます。

各行には次が出ます。

| 位置         | 内容                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 左のアイコン | モデルの画像                                                           |
| 名前 (太字)  | 素のモデルの表示名                                                     |
| 2 行目       | モデル ID。Ollama のモデルは ID の後ろに括弧付きでダイジェストが出ます |
| 右端の札     | 取り込み元の種別 (`openai`、`ollama` など)                             |

取り込まれているモデルが無い場合は「モデルが見つかりません」と表示されます。

## 「モデルを管理」

検索ボックスの右にあるダウンロードのアイコン (「モデルを管理」) を押すと、モデルの実体を操作するダイアログが開きます。

これは**管理に対応した推論エンジン (Ollama) に接続している場合にだけ使えます**。対応する接続が無いときは「管理対応の推論エンジンが見つかりません」と表示されます。

ダイアログでは接続ごとに次の操作ができます。

| 操作                            | 内容                                                                                                               |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 「Ollama.com からモデルをプル」 | モデルタグを入力してモデルをダウンロードします。**同時にダウンロードできるのは 3 つまで**です                      |
| 「モデルを削除」                | 一覧から選んだモデルを削除します                                                                                   |
| 「モデルを作成する」            | モデルタグとモデルファイルの内容を指定してモデルを作ります                                                         |
| 「実験的」                      | 「表示」を押すと開きます。「GGUF モデルをアップロード」で、ファイルまたは URL から GGUF 形式のモデルを取り込めます |

## つまずきやすいところ

- **ここにモデルが出てこない** — 「ワークスペース > 設定 > 接続」で接続が有効になっているか、その接続が無効になっていないかを確認してください。
- **チャットのモデル一覧に出てこない** — この画面のモデルは素のモデルです。「ワークスペース > モデル」でモデルを作らないとチャットには出ません。
- **「モデルを管理」が空になっている** — Ollama への接続がある場合にだけ使える機能です。OpenAI 互換 API だけを使っている配備では利用できません。
