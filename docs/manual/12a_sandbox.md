# ワークスペース: サンドボックス

この文書は、チャットのモデルがコードを実行する場所 (サンドボックス) のファイルを、利用者が自分で見て・整理し・編集する画面の説明です。

## サンドボックスのファイルとは

チャットのモデルは、コードの実行やファイルの読み書きをするとき、サーバー上のサンドボックスを使います。サンドボックスには利用者ごとの作業場と、グループ・全体で共有する置き場があります。この画面は、その中身をモデルを介さずに直接扱うためのファイルブラウザです。

開ける場所は次の 3 種類です。画面上の表記は、モデルから見えるパスと同じ文字列です。

| 場所                       | 中身                                    | 一般の利用者                                           | 管理者                   |
| -------------------------- | --------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `/workspace`               | 自分専用の作業場                        | 読み書きできる                                         | 読み書きできる           |
| `/ext/public`              | 全員で共有する置き場                    | 読むだけ                                               | 読み書きできる           |
| `/ext/groups/<グループ名>` | グループで共有する置き場 (グループごと) | 所属グループのものだけ読み書きできる。それ以外は出ない | 全グループ読み書きできる |

- **`/workspace` は利用者ごとに 1 つで、会話をまたいで残ります。** 前の会話でモデルが作ったファイルも、次の会話で使えます。他の利用者からは見えません。管理者も他人の `/workspace` はこの画面から開けません。
- **`/workspace` の中の `imports/` `exports/` `trash/` だけは期限付きです** (下の「`imports/` と `exports/`」「`trash/` (ゴミ箱)」)。
- **所属していないグループの置き場は、一覧に出ません。** 存在しているかどうかも分かりません。

**同じ場所をチャットのモデルも読み書きします。** モデルがファイルを書く・読む・コマンドを実行するときに使うのも、この画面に出ているのと同じファイルです。この画面でファイルを置けばモデルに読ませることができ、モデルが作ったファイルはこの画面で確認できます。

この画面からチャットへファイルを添付する機能はありません。会話に載せたいファイルは、チャットのモデルに頼んでください。

## どこにあるか

左サイドバー > ワークスペース > 「サンドボックス」

「ファイル」タブの右隣にあります。**サンドボックスを使う配備でだけ表示されます。** タブが無い場合は、その配備ではこの機能を使っていません。

## 誰が使えるか

**ログインしている利用者全員**です (タブが表示される配備で)。

どの場所を開けるか、書き換えられるかは、上の表のとおり役割と所属グループで決まります。読むだけの場所では、アップロード・新規作成・名前の変更・削除・保存のボタン自体が出ません。

アップロードには、さらにグループの権限「ファイルアップロードを許可」(「ワークスペース > ユーザー」の権限。チャットの添付と同じもの) が要ります。許可されていない利用者には、書ける場所でも「アップロード」ボタンが出ず、ドラッグ&ドロップも受け付けません。新規フォルダ・新規ファイルの作成と、開いたファイルの保存はこの権限と関係なくできます。管理者は常にアップロードできます。

## 画面の上部

| 要素                       | 意味                                                                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 「サンドボックス」の見出し | `/workspace` を開いているときは、横に容量のゲージと「使用量 / 上限 GB」が出ます。上限の値は配備によって異なります                            |
| 場所の切り替え             | 今いる場所のパス (例: `/workspace`) が書かれたボタンです。押すと開ける場所の一覧が出ます。**鍵のアイコン**が付いている場所は「閲覧のみ」です |
| 「アップロード」           | ファイル選択ダイアログを開きます。複数選択できます。書ける場所で、アップロードを許可されている利用者にだけ出ます                             |
| フォルダ + のアイコン      | 「新規フォルダ」。書ける場所でだけ出ます                                                                                                     |
| ファイル + のアイコン      | 「新規ファイル」。空のファイルを作って、そのまま編集画面を開きます。書ける場所でだけ出ます                                                   |
| 回転矢印のアイコン         | 「再読み込み」。一覧を読み直します。モデルが書いたファイルを確かめるときに押してください                                                     |

その下に**パンくず**が出ます。`/ext/public / recipes / notes` のように、実際のパスと同じ形で並びます。末尾以外の要素を押すとその階層へ戻ります。階層が深いときは途中が「…」に畳まれ、押すと全部が出ます。

開いている場所・フォルダ・ファイルはブラウザのアドレスに入っています。ブラウザの「戻る」や再読み込みで同じ所へ戻れ、アドレスを他の人に伝えることもできます (相手がその場所を開ける場合に限ります)。

## 一覧

フォルダが先、続いてファイルが名前順に並びます。各行には名前と、ファイルならサイズ、それに更新日時が出ます。

- フォルダの行を押すと中に入ります。
- ファイルの行を押すと、そのファイルを開きます (下の「ファイルを開く・編集する」)。
- **シンボリックリンク**は斜体で表示されます。押しても辿らず、「シンボリックリンクはここでは辿りません。」と出ます。

行にマウスを乗せると、右端にアイコンが出ます (幅の狭い画面では常に出ています)。

| アイコン   | 意味                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 下向き矢印 | 「ダウンロード」。ファイルの行にだけ出ます。フォルダはダウンロードできません       |
| 鉛筆       | 「名前を変更」。書ける場所でだけ出ます                                             |
| ごみ箱     | 「削除」。書ける場所でだけ出ます。`/workspace` ではゴミ箱へ移します (下の「削除」) |

フォルダが空のときは「このフォルダは空です。」と出ます。項目が非常に多いフォルダでは「項目が多すぎるため、先頭の一部だけを表示しています。」と出て、残りは表示されません。

## アップロード

「アップロード」ボタンのほか、**ファイルを一覧の上にドラッグ&ドロップ**してもアップロードできます。アップロード先は今開いているフォルダです。

同じ名前のファイルが既にあるときは「既存のファイルを上書きしますか？」と確認が出ます。

- 「上書き」 — すべて上書きします
- 「既存は飛ばす」 — 同じ名前のものだけを飛ばし、残りをアップロードします

1 ファイルあたりの上限サイズは配備によって異なります (既定 1024 MB。チャットの添付の上限「最大アップロードサイズ」とは別の値で、管理画面からは変えられません)。超えたファイルは「ファイルが大きすぎます(上限 …)。」と出て、アップロードされません。容量 (下の節) が足りないときもアップロードされません。ダウンロードも同じ上限です。

動画などの大きなファイルもアップロードできますが、送り終わるまで時間がかかります。アップロード中はボタンが回転表示になります。

## 新規フォルダ・新規ファイル・名前の変更

いずれも名前を入力するダイアログが開きます。

- **新規フォルダ・新規ファイル** — 今開いているフォルダに作ります。`a/b` のように書くと、途中のフォルダもまとめて作ります。同じ名前が既にあるときは「同じ名前のファイルまたはフォルダが既にあります。」と出て、作られません。
- **名前の変更** — 同じフォルダの中の新しい名前を入力します。`/workspace/archive/old.md` のように `/` で始まるフルパスを書くと、**別のフォルダへ移動**できます。移動できるのは同じ場所の中だけです (`/workspace` から `/ext/public` へ、あるグループから別のグループへ、といった移動はできません)。

**「.」で始まる名前は使えません。** 「.」で始まるファイルやフォルダは一覧にも出ません。

## 削除

ごみ箱のアイコンを押したときの動きは、場所によって違います。

| 場所                           | 確認の文言                   | 結果                                                                            |
| ------------------------------ | ---------------------------- | ------------------------------------------------------------------------------- |
| `/workspace` (`trash/` の外)   | 「… をゴミ箱に移しますか？」 | `/workspace/trash/` の直下へ移します (「ゴミ箱に移す」)。一定期間は元に戻せます |
| `/workspace/trash/` の中       | 「… を完全に削除しますか？」 | 完全に削除します。**元に戻せません**                                            |
| `/ext/public`・`/ext/groups/…` | 「… を削除しますか？」       | 完全に削除します。**元に戻せません**                                            |

- **ゴミ箱に同じ名前があるときは、末尾に `-2`、`-3`… を付けて移します。** 拡張子があれば拡張子の前に付きます (例: `memo.txt` → `memo-2.txt`、フォルダ `data` → `data-2`)。
- 完全に削除するときは、フォルダなら「フォルダと中身がすべて削除されます。元に戻せません。」、ファイルなら「元に戻せません。」と出ます。「ファイル」タブのような削除済みからの復元はありません。
- ゴミ箱から戻すには、「名前の変更」で `/workspace/…` のフルパスを書いて移します (下の「`trash/` (ゴミ箱)」)。

場所の一番上 (`/workspace` そのもの、各グループの置き場そのもの) と、`/workspace` 直下の `imports/` `exports/` `trash/` フォルダは、削除も名前の変更もできません。

## ファイルを開く・編集する

ファイルを開くと、一覧の代わりにそのファイルの画面になります。左上の矢印 (「戻る」) で一覧へ戻ります。上部には「未保存」の印・「閲覧のみ」の印・サイズと更新日時・期限 (`imports/` `exports/` `trash/` の直下のファイルのみ) と、「再読み込み」「ダウンロード」のアイコン、「保存」ボタンが並びます。

### 編集できるファイル

**次の 3 つを満たすファイルだけが、この画面で編集できます。**

- 1 MB 以下 (既定。配備によって異なります)
- 文字コードが UTF-8
- NUL 文字 (バイナリの印) を含まない

それ以外のファイル (画像・PDF・Excel・大きなテキスト・Shift_JIS のテキストなど) は、「このファイルはテキストとして開くには大きすぎます。ダウンロードしてください。」または「このファイルは平文(UTF-8)ではありません。ダウンロードしてください。」と出て、ダウンロードだけができます。

編集画面はコードエディタです。拡張子に応じて色分けされます。

- **保存** — 「保存」ボタン、または **Ctrl+S** (Mac は ⌘+S)。変更が無いときは「保存」は押せません
- 保存していない変更があると、上部に「未保存」の印が出ます。その状態で一覧へ戻る・別の場所へ移る・タブを閉じようとすると、「保存していない変更を破棄しますか？」と確認が出ます

読むだけの場所のファイルは、編集できない表示で中身だけが出ます。

### Markdown のプレビュー

拡張子が `.md` のファイルは、上部に「編集」/「プレビュー」の切り替えが出ます。「プレビュー」では表や見出しを整形して表示します。保存前の編集中の内容もプレビューに反映されます。

読むだけの場所の Markdown は、最初からプレビューで開きます (切り替えの左側は「ソース」になります)。

### 「エディタの外で変更されました」

ファイルを開いてから保存するまでの間に、**チャットのモデルや別のブラウザのタブ**がそのファイルを書き換えていた場合、保存しようとすると「エディタの外で変更されました」というダイアログが出ます。

| ボタン           | 結果                                                                   |
| ---------------- | ---------------------------------------------------------------------- |
| 「編集を続ける」 | 何もせずダイアログを閉じます。自分の編集はそのまま残ります             |
| 「再読み込み」   | 最新の内容を読み込み直します。**保存していない自分の編集は失われます** |
| 「上書き」       | 外での変更を捨てて、自分の内容で上書きします                           |

開いた後にファイルが削除されていた場合は、ボタンが「破棄」(自分の編集を捨てて一覧へ戻る) と「新しく保存」(自分の内容で作り直す) になります。

どちらを選ぶか迷うときは、「編集を続ける」で閉じ、自分の編集内容をコピーしておいてから「再読み込み」で外の変更を確かめるのが安全です。

## `imports/` と `exports/`

`/workspace` の中のこの 2 つのフォルダは、チャットとのやりとりに使われます。

- **`imports/`** — チャットに添付したファイルをモデルが取り込むと、ここに置かれます。
- **`exports/`** — モデルがここにファイルを書くと、そのファイルはチャットへ自動で添付されます。

どちらも中身は**「ファイル」タブにある原本の写し**です。そのため、**直下に置いたものは、置いてから (最後に変更してから) 一定期間が過ぎると自動で削除されます** (既定は 30 日。期間は配備によって異なります)。

- 期限は**このフォルダの直下にあるもの 1 つずつ** (ファイルでもフォルダでも) に付きます。フォルダなら中身ごと消えます。フォルダの中のファイルを後から変更しても、そのフォルダの期限は延びません。
- 直下の各行に「YYYY-MM-DD に削除(残り N 日)」と期限が出ます。残りが少ないものは色が変わり、期限を過ぎたものは「まもなく削除」と出ます。
- 一覧の下に「ここにあるのはチャットの添付・生成物の写しです。このフォルダの直下に置いたもの (ファイルでもフォルダでも 1 つ) は、置いてから (最後に変更してから) N 日で中身ごと消えます。原本は「ファイル」に残ります。」と注記が出ます。
- **消えても原本は残っています。** チャットの添付・生成物は「ファイル」タブにあり、チャットのモデルに頼めば `imports/` へ取り込み直せます。
- 長く残したいファイルは、`imports/` `exports/` の外 (`/workspace` の別のフォルダ) へ移してください。

## `trash/` (ゴミ箱)

`/workspace/trash/` は、`/workspace` で削除したものの移し先です。選び間違えて消したものを取り返せるようにするためのフォルダで、チャットのモデルもファイルを消すときは同じようにここへ移します。

- **直下に置いたものは、ここへ移してから一定期間 (既定は 30 日。`imports/` `exports/` と同じ期間) で自動で完全に削除されます。** 期限は直下にあるもの 1 つずつに付き、フォルダなら中身ごと消えます。中のファイルが古くても、移した日から数えます。
- `/workspace` の一覧では `trash` の行に「削除したもの (移してから N 日で消えます)」と出ます。中に入ると、直下の各行に期限が出て、一覧の下に注記が出ます。
- **元に戻す** — 戻したいものの鉛筆のアイコン (「名前の変更」) を押し、`/workspace/data/memo.txt` のように `/` で始まるフルパスを書きます。移した先に同じ名前があるときは移せないので、別の名前にしてください。
- **ゴミ箱の中で削除すると完全に消えます。** 元に戻せません。
- **ゴミ箱に移しただけでは容量は空きません。** 容量を空けたいときは、ゴミ箱の中で削除してください (下の「容量」)。

## 容量

`/workspace` には利用者ごとの容量の上限があります。見出しの横のゲージで使用量を確認できます。上限の値は配備によって異なります。

容量が一杯になると、アップロードや保存で「workspace の容量が一杯です。ゴミ箱 (/workspace/trash/) を空にすると空きが増えます (ほかの場所での削除はゴミ箱へ移すだけです)。」と出ます。チャットでモデルがファイルを書けなくなったときも同じ原因です。

**`/workspace` で削除してもゴミ箱へ移るだけで、容量は空きません。** 空きを作るには、不要なものをゴミ箱に移したうえで、`/workspace/trash/` を開いてその中で削除 (完全に削除) してください。

`/ext/public` と `/ext/groups/…` には利用者ごとの容量の上限はありません。

## つまずきやすいところ

- **「サンドボックス」タブが無い** — その配備ではサンドボックスを使っていません。
- **グループの置き場が場所の一覧に出ない** — そのグループに所属していません。所属は管理者が「ワークスペース > ユーザー」の「グループ」で設定します。
- **`/ext/public` を開くと「この場所はこのサーバーにはありません。」と出る** — その配備では共有の置き場を用意していません。用意するかどうかは配備によって異なります。
- **アップロードや新規作成のボタンが無い** — 読むだけの場所 (場所の切り替えに鍵のアイコンが付いている所) を開いています。一般の利用者にとって `/ext/public` は読むだけの場所です。
- **新規作成のボタンはあるのに「アップロード」だけが無い** — アップロードを許可されていません。管理者が「ワークスペース > ユーザー」の権限「ファイルアップロードを許可」で設定します。
- **ファイルを開いても編集できない** — 1 MB (既定) を超えている、UTF-8 ではない (Shift_JIS の CSV など)、またはバイナリのファイルです。ダウンロードして手元で扱うか、チャットのモデルに UTF-8 への変換を頼んでください。
- **モデルが作ったはずのファイルが無い** — 一覧は自動では更新されません。「再読み込み」を押してください。
- **`imports/` `exports/` のファイルが消えた** — 期限切れで自動削除されました。原本は「ファイル」タブにあります。
- **削除したのに容量が減らない** — `/workspace` での削除はゴミ箱 (`/workspace/trash/`) へ移すだけです。ゴミ箱の中で削除すると空きます。
- **削除したファイルを戻したい** — `/workspace/trash/` を開き、「名前の変更」で元の場所のフルパスへ移してください。移してから期限 (既定 30 日) が過ぎたものは、もう残っていません。
- **グループ名を変えたら、グループの置き場が空になった** — グループの置き場は**グループ名をそのままフォルダ名**にしています。名前を変えると新しい名前の空の置き場になり、旧名の置き場の中身はこの画面から (管理者も含めて) 開けなくなります。中身を引き継ぐには、管理者がサーバー側で旧名のフォルダの名前を変える必要があります。グループ名に使える文字の制約は「ユーザー」(`16_users.md`) を参照してください。
- **保存しようとしたら「エディタの外で変更されました」と出た** — チャットのモデルが同じファイルを書き換えています。上の節「「エディタの外で変更されました」」の表から選んでください。
