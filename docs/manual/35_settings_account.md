# 設定 — 「アカウント」タブ

この文書は、ユーザー設定ウィンドウの「アカウント」タブにある項目の説明です。
表示名、プロフィール画像、パスワード、API キーを扱います。

## どこにあるか

サイドバーの「設定」(または `Ctrl` + `.`) でウィンドウを開き、左側のタブから「アカウント」を選びます。

## 誰が使えるか

ログインしている全員が、自分のアカウントに対して行えます。
メールアドレスやユーザーの権限 (どのグループに属するか) は、ここでは変更できません。管理者の作業です。

## 項目

| 項目                 | 意味                                                                           |
| -------------------- | ------------------------------------------------------------------------------ |
| 「プロフィール画像」 | 画面右上やサイドバーに出る自分のアイコン。                                     |
| 「名前」             | チャットなどに表示される自分の名前。                                           |
| 「通知 Webhook」     | 通知を外部へ送るための URL。この機能が有効な配備でのみ表示されます。           |
| 「パスワードを変更」 | ログイン用のパスワードを変更します。                                           |
| 「API キー」         | 外部のプログラムから接続するための鍵。この機能が有効な配備でのみ表示されます。 |

**このタブは、変更しても自動保存されません。** 「プロフィール画像」「名前」「通知 Webhook」を変えたら、
必ず右下の「保存」を押してください。保存に成功すると「設定が正常に保存されました！」と表示されます。

## プロフィール画像を変える

1. 画像を押します (カーソルを重ねると鉛筆のアイコンが出ます)。
2. 画像ファイル (GIF / WebP / JPEG / PNG) を選びます。正方形に切り出されて表示されます。
3. 右下の「保存」を押します。

- 「初期値を使用する」 — 名前の頭文字から作られた画像に切り替えます。
- 「削除」 — 既定の画像に戻します。

## 名前を変える

1. 「名前」の欄を書き換えます。
2. 右下の「保存」を押します。

プロフィール画像を設定していない (または頭文字の画像のままの) 場合は、名前を変えると
頭文字の画像も新しい名前に合わせて作り直されます。

## パスワードを変える

1. 「パスワードを変更」の下に 3 つの欄があります。「現在のパスワード」「新しいパスワード」
   「パスワードの確認」をそれぞれ入力します。各欄の目のアイコンで、入力した内容の表示 / 非表示を切り替えられます。
2. 「パスワードを更新」を押します。
3. 成功すると「正常に更新されました。」と表示されます。

新しいパスワードと確認用の入力が一致しない場合は、英語のまま
`The passwords you entered don't quite match. Please double-check and try again.`
と表示され、下 2 つの欄が空になります。入力し直してください。

パスワードの変更はこのボタンだけで確定します。右下の「保存」は不要です。

## API キー

外部のプログラムからこのシステムに接続するときに使う鍵です。ふだんの利用では使いません。

1. 「新しいシークレットキーを作成」を押します。「API キーが作成されました。」と表示されます。
2. 鍵は `*****` で伏せて表示されます。目のアイコンで内容を表示できます。
3. コピーのアイコンでクリップボードにコピーできます。
4. 作り直したいときは、その右の回転する矢印 (「新しいキーを作成」) を押します。
   **古い鍵は使えなくなります。**

作成に失敗した場合は「APIキーの作成に失敗しました。」と表示されます。

## 注意点

- API キーは自分のアカウントとして操作できる資格情報です。他人に渡さないでください。
- 「通知 Webhook」と「API キー」は、配備によっては表示されません。表示されない場合、
  その配備ではその機能が使えません。
