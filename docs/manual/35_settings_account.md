# 設定 — 「アカウント」タブ

この文書は、ユーザー設定ウィンドウの「アカウント」タブにある項目の説明です。
表示名、プロフィール画像、パスワード、API キーを扱います。

## どこにあるか

サイドバーの「設定」(または `Ctrl` + `.`) でウィンドウを開き、左側のタブから「アカウント」を選びます。

## 誰が使えるか

ログインしている全員が、自分のアカウントに対して行えます。
メールアドレスやユーザーの権限 (どのグループに属するか) は、ここでは変更できません。管理者の作業です。

## 項目

| 項目                 | 意味                                                                                                        |
| -------------------- | ----------------------------------------------------------------------------------------------------------- |
| 「プロフィール画像」 | 画面右上やサイドバーに出る自分のアイコン。                                                                  |
| 「名前」             | チャットなどに表示される自分の名前。                                                                        |
| 「通知 Webhook」     | 応答の完了を外部へ知らせるための URL (下の「通知 Webhook」)。管理者が有効にしている配備でのみ表示されます。 |
| 「パスワードを変更」 | ログイン用のパスワードを変更します。                                                                        |
| 「API キー」         | 外部のプログラムから接続するための鍵。この機能が有効な配備でのみ表示されます。                              |

**このタブは、変更しても自動保存されません。** 「プロフィール画像」「名前」「通知 Webhook」を変えたら、
必ず右下の「保存」を押してください。保存に成功すると「設定が正常に保存されました！」と表示されます。

## プロフィール画像を変える

1. 画像を押します (カーソルを重ねると鉛筆のアイコンが出ます)。
2. 画像ファイル (GIF / WebP / JPEG / PNG) を選びます。正方形に切り出されて表示されます。
3. 右下の「保存」を押します。

- 「頭文字を使う」 — 名前の頭文字から作られた画像に切り替えます。
- 「削除」 — 既定の画像に戻します。

## 名前を変える

1. 「名前」の欄を書き換えます。
2. 右下の「保存」を押します。

プロフィール画像を設定していない (または頭文字の画像のままの) 場合は、名前を変えると
頭文字の画像も新しい名前に合わせて作り直されます。

## パスワードを変える

1. 「パスワードを変更」の下に 3 つの欄があります。「現在のパスワード」「新しいパスワード」
   「パスワードの確認」をそれぞれ入力します。各欄の目のアイコンで、入力した内容の表示 / 非表示を切り替えられます。
2. 「パスワードを更新」を押します。
3. 成功すると「正常に更新されました。」と表示されます。

新しいパスワードと確認用の入力が一致しない場合は、
「入力したパスワードが一致しません。確認してもう一度お試しください。」
と表示され、下 2 つの欄が空になります。入力し直してください。

「現在のパスワード」が違う場合は、
「The password provided is incorrect. Please check for typos and try again.」
と表示され、3 つの欄がすべて空になります。パスワードは変わっていません。

ここで変えられるのは、nucllei のアカウントのパスワードだけです。次の場合は、この画面ではパスワードを変えられません。

- **LDAP でサインインしている場合** — LDAP のパスワードを入れても「現在のパスワード」が違うというエラーになります。
  パスワードは LDAP の側で変更してください。
- **配備がヘッダー認証 (前段の認証基盤からの引き継ぎ) を使っている場合** — 欄は表示されますが、「パスワードを更新」を押すと
  「The requested action has been restricted as a security measure.」と表示され、変更されません。

パスワードの変更はこのボタンだけで確定します。右下の「保存」は不要です。

## API キー

外部のプログラムからこのシステムに接続するときに使う鍵です。ふだんの利用では使いません。

1. 「新しいシークレットキーを作成」を押します。「API キーが作成されました。」と表示されます。
2. 鍵は `*****` で伏せて表示されます。目のアイコンで内容を表示できます。
3. コピーのアイコンでクリップボードにコピーできます。
4. 作り直したいときは、その右の回転する矢印 (「新しいキーを作成」) を押します。
   **古い鍵は使えなくなります。**

作成に失敗した場合は「APIキーの作成に失敗しました。」と表示されます。

管理者が API キーを無効にすると、この欄は表示されなくなり、**すでに作成済みの鍵も使えなくなります**
(鍵を使ったリクエストは「Use of API key is not enabled in the environment.」で拒否されます)。

## 通知 Webhook

「通知 Webhook」に URL を入れて「保存」しておくと、**自分のチャットの応答が完了したとき、その応答を受け取っている
ブラウザが 1 つもなければ**、その URL へ通知が送られます。たとえば、応答の途中でタブやブラウザを閉じた場合です。
通知には、チャットのタイトル、チャットへのリンク、応答の本文が入ります。

nucllei を開いているブラウザは、別のチャットやワークスペースに移っても応答を受け取り続けます。その間は送られません
(「一般」タブの「デスクトップ通知」をオンにしていれば、そちらで知らせます。[31 一般](31_settings_general.md))。
止めたいときは、欄を空にして「保存」します。

## 注意点

- API キーは自分のアカウントとして操作できる資格情報です。他人に渡さないでください。
- 「通知 Webhook」と「API キー」は、配備によっては表示されません。
- 「通知 Webhook」の欄が表示されないのは、管理者が通知 Webhook を無効にしている配備です。その間は通知が送られません。前に保存した URL は消えずに残り、管理者が有効に戻すとまた送られます。
