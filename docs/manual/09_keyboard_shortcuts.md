# キーボードショートカットと入力コマンド

この文書は、チャット画面で使えるキーボードショートカットと、入力欄で使える記号コマンドの一覧です。

## どこにあるか

画面が広いとき、チャット画面の右下すみに小さな `?` ボタンがあります。押すと
「キーボードショートカット」のウィンドウが開きます。`Ctrl` + `/` (Mac は `⌘` + `/`) でも開けます。

## 誰が使えるか

ログインしている全員が使えます。

## ウィンドウに載っているショートカット

以下の `Ctrl` は、Mac では `⌘` に読み替えてください。

| 動作 | キー |
| --- | --- |
| 新しいチャットを開く | `Ctrl` + `Shift` + `O` |
| チャット入力をフォーカス | `Shift` + `Esc` |
| 最後のコードブロックをコピー | `Ctrl` + `Shift` + `;` |
| 最後の応答をコピー | `Ctrl` + `Shift` + `C` |
| プロンプトペアを生成 | `Ctrl` + `Shift` + `Enter` |
| 設定を切り替え | `Ctrl` + `.` |
| サイドバーを切り替え | `Ctrl` + `Shift` + `S` |
| チャットを削除 | `Ctrl` + `Shift` + `⌫` / `Delete` |
| 「表示」(このショートカット一覧を開く) | `Ctrl` + `/` |

「プロンプトペアを生成」は、モデルを呼び出さずに、入力中の文面を自分の発言として、
プレースホルダーの応答と対にして会話に書き加えるものです。

## ウィンドウに載っている入力コマンド

| 動作 | キー |
| --- | --- |
| スキルを起動 | `/` |
| モデルと話す | `@` |
| プロンプト変数へジャンプ | `TAB` |

- `/` — **入力欄の 1 行目の行頭**で打つと、使えるスキルの一覧が出ます。
- `@` — モデルの一覧が出ます。選ぶと、その送信 1 回だけそのモデルが応答します。
- `TAB` — 文中の `{{...}}` のような差し込み箇所を順に選択します。

一覧が開いている間は、`↑` `↓` で候補を選び、`Enter` または `Tab` で確定します。

## 入力欄で使えるその他のキー操作

| 動作 | キー | 補足 |
| --- | --- | --- |
| 送信 | `Ctrl` + `Enter` (既定) または `Enter` | どちらになるかは設定によります。送信ボタンにカーソルを重ねると現在の割り当てが出ます。 |
| 改行 | `Enter` (既定) または `Shift` + `Enter` | 上と対になります。 |
| 直前の自分のメッセージを編集 | `↑` | 入力欄が空のときだけ。 |
| 最後の応答を再生成 | `Ctrl` + `R` | 入力欄が空のときだけ。 |
| 応答の生成を止める | `Esc` | |
| `@` で選んだモデルの指定を外す | `Esc` | |

メッセージの編集中は、`Ctrl` + `Enter` で「送信」、`Esc` で「キャンセル」になります。

## 注意点

- ブラウザ自体のショートカットと重なるものがあります (`Ctrl` + `R` など)。
  入力欄が空でないときは働かない、といった条件があるので、上の表の補足も確認してください。
- `?` ボタンは画面幅が狭いときは表示されません。`Ctrl` + `/` を使ってください。
