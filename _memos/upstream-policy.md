# upstream(open-webui/open-webui)取り込みポリシー

本 fork は **v0.6.5**(最後の無制約 BSD-3-Clause 版、`07d8460126a686de9a99e2662d06106e22c3f6b6`)を基点とする。
v0.6.6 でブランディング条項が導入されており、それ以降のコードの混入はライセンス上の
派生著作物リスクになるため、以下を厳守する。

## 原則

1. **無条件マージ禁止。** upstream ブランチの merge / rebase は行わない。
2. **クリーンルーム原則。** v0.6.6 以降の upstream ソースコードを読まない・写さない。
   タグ間 diff の実装内容の閲覧もソースコードの閲覧に含まれる。
3. 取り込み(cherry-pick)が必要な場合はファイル/コミット単位で選択的に行い、
   下記フォーマットで由来を記録する。ただし v0.6.5 以前のコミットに限る。

## 参照してよいもの / いけないもの

| 可否 | 対象 |
|---|---|
| 可 | リリースノート・CHANGELOG(記述テキスト) |
| 可 | 公式ドキュメント(docs.openwebui.com) |
| 可 | API の外形仕様(OpenAI / vLLM 等の公式仕様書) |
| 可 | タグ間 diff の**規模・ファイル名・関数名レベル**の把握(`diff --stat` 等) |
| **不可** | v0.6.6 以降のソースコード本体(実装ロジックの閲覧・参考・移植) |
| **不可** | v0.6.6 以降のコミットの cherry-pick |

機能を再実装する場合は、外形仕様・公式ドキュメント・自前設計のみを根拠にする。

## 取り込み記録

```

```

## upstream リリースの確認記録

新リリースの存在確認(タグ・リリースノートの閲覧)は可。確認したら下記を更新する。
